# 余烬农场 v0.10.0「归于生活」

单人中文 HTML/Canvas 末日经营游戏。十张地图，农业、生产、远征、居民、防御和调查共同推进四章重建。沿用像素素材和统一高难度，浏览器本地保存。

在线地址：https://ember-farm.qq5756198.chatgpt.site

## 本轮

统一正式家园入口，移出开发说明、参考链接、点位编号与演示快捷功能；增加真实田地驱动的起步指引和地区通路机会。正式存档键不变，历史独立存档保留；损坏主档不会覆盖有效备份，新游戏与导入有确认和替换前恢复检查点。

标题页提供继续游戏、开始新游戏、设置、制作人员。版本号在标题角落与设置可见。

## 验证与发布状态

210项自动化测试和实际控制器的DOM替身检查通过。真实浏览器、实际触控与200%缩放尚未验收，因此此版为v0.10.0，尚未标记v1.0.0。完整已完成、待完善和待验证清单见 [docs/ITERATION-LEDGER.md](docs/ITERATION-LEDGER.md)。

- `npm test`：游戏、资源、成长、迁移和存档检查。
- `npm run test:ui`：实际game.js控制器＋DOM替身＋原生Canvas；不是浏览器CSS测试。
- `dist/`：站点发布资源。开发清单、历史报告与参考出处位于 `docs/`，没有游戏内开发入口。
- 历史版本记录：`docs/releases/`；旧公开报告与README：`docs/development/`。

## 操作

WASD/方向键移动，E交互，左键使用工具，Tab背包，C制作，B建造，M地图，N/F营地手册，Esc设置。触屏提供摇杆和使用/交互按钮。菜单打开及页面关闭时，世界暂停。

## 保存

正式键：`ember-farm-save-v1`，备用键：`ember-farm-backup-v1`。新游戏和导入分别保留 `ember-farm-before-new-v1`、`ember-farm-before-import-v1` 检查点。设置中可导出当前家园或历史与恢复文件，并通过导入选择恢复检查点。显示设置独立于家园存档。

旧版独立试玩槽位保持原字节，不会覆盖正式家园；已从正式游戏移出其启动功能。清理浏览器数据前应导出备份。

## 素材

继续使用本项目现有farm、ruins、sprites、expansion、frontier像素素材。五张地区底图由 `district-art.js` 生成。没有引入参考游戏的原版素材。
