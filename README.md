# 余烬农场 v0.50.0「落脚」

单人中文 HTML/Canvas 末日经营游戏。你在一座废弃农场落脚，种地、接人、盖东西、出门翻物资，守住一场比一场大的尸潮，把一片地方一点点接回来。画面是代码画的原创像素画，声音和音乐是代码合成的；只做电脑版（窗口 1366×768 到 1920×1080）。

**这一版是重构的第一版。** 从 v0.50 起，游戏按《余烬农场：重构方案（单人经营 · 五章）》改成一条主线、五章：

| 章 | 名字 | 这一章做什么 | 把关的考验 | 状态 |
|---|---|---|---|---|
| 一 | 落脚 | 把破农场变成能过夜的营地 | 第一场尸潮 | **v0.50 能完整玩** |
| 二 | 营地 | 养活六个人，车队到站，集市开张 | 灰隼团来袭 | 下一版 |
| 三 | 前哨 | 通电开工，收回五片地区，熬过寒潮 | 寒潮里的第一个长夜 | 之后 |
| 四 | 据点 | 管一片地区：五张边境图、地铁隧道 | 两个长夜，打赢三凶 | 之后 |
| 五 | 重光 | 把余烬地区接回外面，守住最后一夜 | 最后一夜 | 之后 |

v0.50 只回答两件事：**新界面像不像成品，第一章有没有代入感**。第二到第五章的内容（代码都还在引擎里）先锁着，之后一章一版放出来。

## 怎么玩

```bash
python3 -m http.server 8000 --directory dist
# 浏览器打开 http://localhost:8000
```

`dist/` 是一个纯静态页面，任何静态服务器都行；不需要构建，不需要联网。

| 键 | 做什么 |
|---|---|
| W A S D / 方向键 | 走；按住 Shift 跑 |
| E | 和最近的东西交互（画面下方那一行写着会做什么） |
| 鼠标左键 | 用手上的东西（锄头、水壶、种子、武器、干粮、绷带） |
| 1–9、0 | 换手上的东西 |
| 空格 / X | 翻滚 / 推开（被抓住、被围住时） |
| R / V / G | 装填 / 蹲下（草丛里不容易被看见）/ 往鼠标那儿扔一块石头，把感染者引开 |
| B / T / I / M / J | 建造 / 队友 / 仓库 / 地图 / 手记（再按一次关上） |
| C | 仓库里的“生产”（做饭、做东西） |
| Q | 建造时转方向；按住 Shift 连着放 |
| P / Esc | 暂停 / 设置（存档、导出、导入、音量、回标题） |

存档在浏览器里（键 `ember-farm-r1`），自动存；设置页可以导出成文件、从文件导入。**v0.46 及以前的存档这一版读不了**（数据全改了；浏览器里的旧档不会被删）。

## 第一章〈落脚〉里有什么

- **五段**：先让这片地长出口粮 → 守住东边的路口 → 把阿禾接回来、让她住下 → 天黑以前备好 → 守住第一场尸潮。左下角永远写着眼下这一步，手记（J）里有全部。
- **三张地图**：余烬农场、幸存者集市、废弃居民区。别的地方地图上看得见，第二章以后才去得了。
- **两个队友**：搬运的铁锹（回信那天来）、种地的阿禾（从居民区接回来）。他们吃饭、干活、会说话；考验那一夜你倒下一回，铁锹会把你拖回农舍。
- **十三样能建的**：农田、雨水桶、稻草人、堆肥桶、育种箱、仓库箱、篝火灶、制作台、武器工作台、床位、围栏、大门、路障陷阱。
- **出门一趟**：翻开头一个柜子以后，三样好处里挑一样，只管这一趟。
- **备战五样**：三天的口粮、八段围栏和大门、两个陷阱、四份绷带或药包、一个育种箱。
- **第一场尸潮**：第 9 天夜里 21:00，10–16 只，都从东边的路口进来（仓库里的粮越多、围栏越多，来得越多）。第 8 天起备好了可以提前一晚迎战；没守住，下一个夜里重来。
- 做完以后可以留在农场接着经营。

## 界面

整套界面在 v0.50 重写，旧界面的脚本和样式全部删掉：

- `dist/index.html`：页面骨架。
- `dist/app.css`：唯一一份样式表（颜色、字号、按钮、卡、标签都在这里定一次）。
- `dist/app.js`：主程序（存档、键盘鼠标、每一帧、开哪一页）。
- `dist/app-kit.js`、`app-hud.js`、`app-pages.js`、`app-cards.js`：公用小件、常驻的七块、整页、小卡和过场。

常驻的只有七块：顶上的资源（每个数字点开是“从哪来、到哪去”）、右上的日期天气和暂停快进、右边最多三条警报、左下的目标、底下的身体和手上的东西、右下五个按钮、画面上的一行提示。字不小于 14px。

## 代码怎么摆

- `dist/engine.js` 到 `dist/ahead.js`：41 层引擎，一层 `extends` 一层（种地、战斗、居民、季节、长夜、巨怪……都在这里）。
- `dist/chapter.js`、`dist/chapter-data.js`：v0.50 新加的最上面一层——五章、每章开什么、第一章的五段、备战、考验、队友的话、出门一趟的好处。`dist/campaign.js` 只是把它转出去。
- `dist/*-renderer.js`：画面，一层一层叠；`dist/audio*.js`：声音。
- `tests/`：`node --test tests/*.test.mjs`。`tests/chapter.test.mjs` 是这一版新加的。
- `scripts/ch1-bot.mjs`：照手记走第一章的机器人（不开浏览器，量时长、钱粮、倒下几回）。
- `scripts/play-ch1.py`：真浏览器里用键盘鼠标从标题页玩到第一章结束；`SAVE=存档.json` 从一份存档起只练一段。
- `scripts/check-ui.py`：真浏览器里把每一页、每张卡在两个窗口大小下量一遍（字号、出不出画面、字溢不溢出、有没有开发用词、报不报错）。
- `scripts/check-toasts.py`：左上角的消息压不压别的（画面、资源明细、每一页）。
- 其余 `scripts/*-bench.mjs`、`*-sim.mjs`：以前各版量后面几章系统用的台子，现在直接走 `dist/ahead.js`。

```bash
npm install --no-save @napi-rs/canvas@0.1.100   # 只有几个画图的测试要用
npm test                                         # 全部测试
node scripts/ch1-bot.mjs 1,2,3                   # 第一章机器人，三个种子
SAVES=/tmp/saves node scripts/ch1-bot.mjs 1      # 顺手每一段存一份档
python3 scripts/check-ui.py /tmp/saves/seed1-prep.json /tmp/saves/seed1-gate.json /tmp/saves/seed1-end.json
python3 scripts/check-toasts.py /tmp/saves/seed1-prep.json
python3 scripts/play-ch1.py /tmp/play 110        # 真键盘鼠标玩一遍，最多 110 分钟
SAVE=/tmp/saves/seed1-prep.json python3 scripts/play-ch1.py /tmp/drill 8   # 从备战那一段起练 8 分钟
```

## 这一版量出来的数、没做的事

见 `docs/releases/v0.50.0.md` 和 `docs/ITERATION-LEDGER.md`。要紧的几条：

- 后面四章的系统还在引擎里、被第一章这一层挡着；方案里说要删的旧系统和读旧档的代码，这一版**只删了界面那一层和入口**，引擎各层里的还没删。
- 第一章照手记走大约 90–100 分钟（不算停在页面上看字的时间），在“每章 1.5–3 小时”的下沿。
- v0.46 以前的说明在 `docs/development/README-v0.46.0.md`，各版发布说明在 `docs/releases/`。
