# 余烬农场 v0.23.0「回响」

单人中文 HTML/Canvas 末日经营游戏。十五张地图，农业供给、生产工程、远征收复、居民生活、防御战斗、调查复兴六种玩法共同推进家园重建。画面全部是代码画的原创像素画，声音和音乐也全部是代码合成的；前期感染者更凶，靠防具、各种武器和翻滚活下来；统一高难度，浏览器本地保存。

原在线地址（v0.12.0）：https://ember-farm.qq5756198.chatgpt.site 。本仓库没有该站点的部署权限，v0.13.0 至 v0.23.0 都没有覆盖原地址。

## 本轮

按《手感、惊喜与节奏改造方案》做第一版，五个待定项都按推荐做；第二版 v0.24.0「暗涌」做搜东西随机、新感染者和头目，第三版 v0.25.0「长夜」做终局、出身、二周目和打磨，种菜第二轮顺延到 v0.26.0。

- **声音**：全部用代码合成——6 段跟着紧张程度走的音乐、6 句短乐句、10 套环境声（十五张图都有，带雨、雷、雪）、五种感染者的低吼、喊叫和出手、和画面同时响的预兆音、按武器分的挥动和命中、三把枪、按地面分的脚步、心跳；有远近左右，隔墙发闷。设置里四个音量（总、音乐、环境、音效），加一个“声音提示”开关，给听不到的玩家在画面下方写带方向的一行字。
- **打击感**：打中顿一下（越重顿得越久）、挨打往后仰、重击踉跄、打死倒在地上留尸体和血迹（重甲是铁片），重击震屏；“减少闪烁与震屏”下停顿减半、不震。
- **翻滚**：空格（手柄 B、触屏“翻滚”）：110 远、前 0.25 秒不受伤，15 体力，穿得越重滚得越近、越费力。空格原来的“使用”改成只用左键。
- **少打断**：06:00 的每日抉择可以“稍后再选”，12:00 前选；平安的早上不弹日终总结，只给一行提示；任务手记最上面一栏“今天”列三件要紧事，点一下带路。
- **新档开局**：13:00 东边路口来几个感染者，提示条一次教一件事（拿木棍、打、推开、翻滚、踩），打不死人；打退后在路口建一段围栏，给一块破布头巾。
- **按键**：帮助只先列 11 条，其余放进“更多按键”；按住 Tab 是轮盘（制作、建造、地图、手记、技能、消息、防线、拍照）。
- **生涯记录**：成就册里记下每一趟出门（去哪、穿什么、结果、多久、掉多少血、被抓被咬几次、滚了几次），按地图和三段汇总，只留最近 200 趟。

详见 [docs/releases/v0.23.0.md](docs/releases/v0.23.0.md)。上一轮（装备防具）见 [docs/releases/v0.22.0.md](docs/releases/v0.22.0.md)。

标题页提供继续游戏、开始新游戏、设置、制作人员。版本号显示在标题页角落与设置底部。

## 运行

无需构建。用 HTTP 服务打开（不要用 file:// 双击）：

    python3 -m http.server 8000 --directory dist

然后访问 http://localhost:8000 。

## 验证

- `npm test`：665 项游戏、存档、迁移、故事、前哨、寒潮、四季、远方、每日抉择、妙手、种菜、画面、装备、手感与声音检查（画面检查要 `@napi-rs/canvas`，没装时自动跳过）。
- `npm run test:ui`：实际 game.js 控制器 + DOM 替身 + 原生 Canvas（需先 `npm install --no-save @napi-rs/canvas@0.1.100`）。不等同浏览器 CSS 验收。
- `npm run sim:gear`：用正式代码让机器人出门搜刮，看死亡率和一场仗多久；`node scripts/gear-sim.mjs 次数 天数 地图 打法` 跑别的组合，加 `ROLL=telegraph` 或 `ROLL=crowd` 让机器人翻滚（用法写在脚本开头）。
- 本轮另用无头 Chromium 检查了声音、开局那一拨、翻滚、尸体血迹、轮盘、音量、稍后再选、手记“今天”和生涯记录（1366×768、1920×1080、390×844 触屏、844×390 横屏触屏）；真机与其他浏览器仍待验证。完整清单见 [docs/ITERATION-LEDGER.md](docs/ITERATION-LEDGER.md)。

## 操作

WASD/方向键移动，Shift 跑步，空格翻滚，E 交互（几样东西挨在一起时先选，数字键快选；在田边按 E 依次是收获、拔草、捉虫、开垦、浇水、照看，空田是选种；被抓住时连按 E 挣开，爬行者跟前按 E 踩），X 推开（被抓住时立刻挣开），V 蹲行（蹲着靠近人按 E 下手，小游戏里空格抽、Esc 收手），K 技能页，左键使用工具或攻击，Tab 背包与装备栏（按住是轮盘），快捷栏 4 近战、5 远程（再按 5 换下一把）、6 投掷、7 陷阱，C 制作，B 建造，M 地图，J 任务手记，F 远征途中选下一站，L 消息记录，Z 防线视图，Esc 设置。按键可在设置里改（字母键），也支持手柄（LT 推开、RT 跑步、B 翻滚）。触屏提供摇杆和翻滚/使用/交互/推开按钮，窄屏右上角“☰ 菜单”打开快捷页（拍照在这里）。菜单打开及页面关闭时，世界暂停。

## 保存

正式键 `ember-farm-save-v1`，备用键 `ember-farm-backup-v1`，设置键 `ember-farm-preferences-v1`。新游戏和导入分别保留 `ember-farm-before-new-v1`、`ember-farm-before-import-v1` 检查点；旧档第一次升级到 v0.13.0 及以后版本前保留 `ember-farm-before-alliance-v1`；v0.14.0–v0.23.0 没有新增存档键，只在存档里新增 `outpost`、`winter`、`seasons`、`far`、`daily`、`skills`、`theft`、`garden`、`gear`、`feel` 字段，偏好键里多存无障碍选项、改过的键位和四个音量（`audio`，不进存档）。v0.21.0 的新旧画面选择存在 `ember-farm-visual-v1`；v0.22.0 去掉了开关，这个键不再读也不再写，存的“原画面”会被忽略。设置中可导出当前家园或历史与恢复文件，并通过导入选择恢复检查点。旧版独立试玩槽位保持原字节，不会覆盖正式家园。

## 素材

画面里的地图、人物、感染者、防具和武器、建筑、物件、作物和光影都是代码画的原创像素画；音乐、环境声和音效都是代码合成的，包里没有音频文件；物品图标、动物和鸡窝由原图按调色板转成像素。标题、数字、按钮用的融合像素体是开源字体（SIL OFL 1.1，许可随包附在 `dist/fonts/OFL-fusion-pixel.txt`）。原来的 farm、ruins、sprites、expansion、frontier 像素素材还留在包里，物品图标和动物从它们转换；援建队员与灰隼团枪手由现有人物精灵重新着色并加画头饰；营地、终端、水槽、餐桌、出货箱、篷车、机床、运输骡与人物立绘为程序绘制像素图形。没有引入参考作品的原版素材。
