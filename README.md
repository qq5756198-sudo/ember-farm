## 本轮

画面与界面大升级的第三版「删繁」：按《余烬农场：一物一用简化方案》做“并掉和去掉”的那一批（五版：一套 → 看得清 → 删繁 → 上手 → 四季）。只改电脑版；手机上打开也是这一版的玩法，界面照旧。

- **能建的设施 26 样**（原来 39 格）：雨水桶、太阳能板、照看机、药柜拆掉、材料全退；土酒坛原地换成腌缸（腌菜也酿酒）；地板、椅子、灯、书架、餐桌、奖杯并成“摆件”一格；设施改良去掉（改好的照样算）；喷灌头一直开着。
- **种地只剩种、浇、收和一种肥**：浇一次管到第二天早上 8 点；从种下起天天浇上水的，收的时候七成机会多一份优质；喷灌头旁边、水渠边的田每天自己有水，蓄水池、旧水厂、风车每天替你浇几块；照看、肥力（一直 85）、搭配、轮作、盖布、杂草、菜青虫、水网、偷菜去掉，三种肥并成一种，鸡舍自己转；走近一块田，头上写“该浇水”“浇过了”“漏浇过”。
- **营地一个士气**：心情、来劲、疲劳、舒适度和房间、生活水准、伤员和医务室、法令簿、食堂口碑并成一个数，每晚往该有的数走四成；高了加工做饭快一成，低了慢一成；菜单最上面一行点开是它的卡。顶栏 6 个数（“动静”去掉）。
- **去掉的**：动静、电台节目和指令、机床加急、手气签、夜里的抉择、鸽子来信、门缝纸条、商队假货、贺满仓垫付、鼎丰物资、出货箱挂牌、妙手（经验折给探索）、远征路线页；地区里出的东西直接进农场仓库。喜好明着写，麦穗只要摸，天赋按顺序自己学。1366 下 18 个页面上的字少了 12%、按钮少了 14%（技能页 36 个按钮剩 9 个，通信站 10 个剩 1 个）。
- **旧档**：读进来前原样留一份，拆掉的设施材料全退、只退一次，消息里一条“这次简化退回了什么”；第 70、115、200、500 天四份旧档都读过、存过、再读过。
- **台子**：同一批种子的凶台、旧头目台、尸潮台、守夜台和 v0.41.0 一样（只差“伤员”那一栏，这一版没有人躺下）；搜东西每趟 −1.4%；种田台勤快的 +2.4%、忙的 0.0%（两种原来靠水网的布置多收两成上下，见发行记录）。浸泡五个种子各 120 个回合（第 212–214 天）每个回合存档读回 0 问题、127 个长夜都守住。1920 下农场白天、夜里、暴雨夜、长夜第三波、十凶都是中位 59.9 帧，载入 1.38 秒。

## 运行

无需构建。用 HTTP 服务打开（不要用 file:// 双击）：

    python3 -m http.server 8000 --directory dist

然后访问 http://localhost:8000 。

## 素材

画面里的地图、人物、感染者、防具和武器、建筑、物件、作物、物品图标、动物和光影都是代码画的原创像素画（物品图标和动物从 v0.25.0 起）；音乐、环境声和音效都是代码合成的，包里没有音频文件；少数扩建物件仍由原图按调色板转成像素。标题、数字、按钮用的融合像素体是开源字体（SIL OFL 1.1，许可随包附在 `dist/fonts/OFL-fusion-pixel.txt`）。原来的 farm、ruins、sprites、expansion、frontier 像素素材还留在包里，少数扩建物件从它们转换；援建队员与灰隼团枪手由现有人物精灵重新着色并加画头饰；营地、终端、水槽、餐桌、出货箱、篷车、机床、运输骡与人物立绘为程序绘制像素图形。没有引入参考作品的原版素材。
