# 余烬农场 v0.24.0「暗涌」

单人中文 HTML/Canvas 末日经营游戏。十五张地图，农业供给、生产工程、远征收复、居民生活、防御战斗、调查复兴六种玩法共同推进家园重建。画面全部是代码画的原创像素画，声音和音乐也全部是代码合成的；前期感染者更凶，靠防具、各种武器和翻滚活下来；废墟里每天亮的柜子、摆法和小事件都不一样，第 4 天起有新感染者和头目；统一高难度，浏览器本地保存。

原在线地址（v0.12.0）：https://ember-farm.qq5756198.chatgpt.site 。本仓库没有该站点的部署权限，v0.13.0 至 v0.24.0 都没有覆盖原地址。

## 本轮

按《手感、惊喜与节奏改造方案》做第二版（第一版 v0.23.0「回响」做了声音、打击感、翻滚、少打断和开局）；第三版 v0.25.0「长夜」做终局、出身、二周目和打磨，种菜第二轮顺延到 v0.26.0。

- **搜东西随机**：居民区、医院、仓库各 9 个候选柜子，每天随机亮 4–5 个；七种柜子按普通、少见、稀有、珍贵四档抽，越往后好东西越多；锁着的铁柜要用撬棍撬（8 秒、很响，学了「开锁」4 秒没声音）；抽到稀有、珍贵会闪光、响一声。抽什么按存档种子定，读档不重抽。
- **感染者换摆法**：三张废墟每一段 3 套摆法，每次刷新抽一套。
- **废墟里的小事件**：被困的人、空投、尸堆、锁着的储藏室、灰隼团的搜索队、背包客、对讲机，第 2 天起每天 35% 的机会；地图上一块小牌子，修好电台的早上 7 点播出来。
- **新感染者**：膨胀者（死了炸开一团毒雾）、装死者（躺在尸体里抓脚踝）第 4 天起；吐酸者（远处吐一滩酸）、夜行者（夜里绕到背后扑，怕光和火）第 8 天起。
- **头目**：大块头（居民区，砸地、扔车门）、护士长（医院，尖叫叫人、绿光回血）每 7 天出现一天，前一天告诉你；仓库守卫第 4 天起加强（正面有甲要绕背，甲掉了连续冲撞）。血条在屏幕上方，不弹窗；第一次打赢奖励翻倍，战利品可以捐给档案馆。
- **接上原来的东西**：电台播报、档案馆第六个展柜、宵禁挡住夜行者、三张新的每日抉择卡、麦穗冲装死的叫；手记里“废墟里的动静”能标出位置。

详见 [docs/releases/v0.24.0.md](docs/releases/v0.24.0.md)。上一轮（声音、手感、翻滚）见 [docs/releases/v0.23.0.md](docs/releases/v0.23.0.md)。

标题页提供继续游戏、开始新游戏、设置、制作人员。版本号显示在标题页角落与设置底部。

## 运行

无需构建。用 HTTP 服务打开（不要用 file:// 双击）：

    python3 -m http.server 8000 --directory dist

然后访问 http://localhost:8000 。

## 验证

- `npm test`：702 项游戏、存档、迁移、故事、前哨、寒潮、四季、远方、每日抉择、妙手、种菜、画面、装备、手感、声音与暗涌检查（画面检查要 `@napi-rs/canvas`，没装时自动跳过）。
- `npm run test:ui`：实际 game.js 控制器 + DOM 替身 + 原生 Canvas（需先 `npm install --no-save @napi-rs/canvas@0.1.100`）。不等同浏览器 CSS 验收。
- `npm run sim:gear`：用正式代码让机器人出门搜刮，看死亡率和一场仗多久；`node scripts/gear-sim.mjs 次数 天数 地图 打法` 跑别的组合，加 `ROLL=telegraph` 或 `ROLL=crowd` 让机器人翻滚（用法写在脚本开头）。
- `npm run sim:loot`：搜东西随机以后每趟平均拿到的和以前比；`npm run sim:boss`：头目战的胜率、死亡率和一场多久（用法都写在脚本开头）。
- 本轮另用无头 Chromium 检查了头目血条、各种预兆（白天、夜里、色弱、减少闪烁）、柜子和撬锁、七种小事件、地图小牌子、手记、档案馆和成就册（1366×768、1920×1080、390×844 触屏、844×390 横屏触屏）；真机与其他浏览器仍待验证。完整清单见 [docs/ITERATION-LEDGER.md](docs/ITERATION-LEDGER.md)。

## 操作

WASD/方向键移动，Shift 跑步，空格翻滚，E 交互（几样东西挨在一起时先选，数字键快选；在田边按 E 依次是收获、拔草、捉虫、开垦、浇水、照看，空田是选种；被抓住时连按 E 挣开，爬行者和地上装死的跟前按 E 踩，锁着的柜子前按 E 撬、再按一下停），X 推开（被抓住时立刻挣开），V 蹲行（蹲着靠近人按 E 下手，小游戏里空格抽、Esc 收手），K 技能页，左键使用工具或攻击，Tab 背包与装备栏（按住是轮盘），快捷栏 4 近战、5 远程（再按 5 换下一把）、6 投掷、7 陷阱，C 制作，B 建造，M 地图，J 任务手记，F 远征途中选下一站，L 消息记录，Z 防线视图，Esc 设置。按键可在设置里改（字母键），也支持手柄（LT 推开、RT 跑步、B 翻滚）。触屏提供摇杆和翻滚/使用/交互/推开按钮，窄屏右上角“☰ 菜单”打开快捷页（拍照在这里）。菜单打开及页面关闭时，世界暂停。

## 保存

正式键 `ember-farm-save-v1`，备用键 `ember-farm-backup-v1`，设置键 `ember-farm-preferences-v1`。新游戏和导入分别保留 `ember-farm-before-new-v1`、`ember-farm-before-import-v1` 检查点；旧档第一次升级到 v0.13.0 及以后版本前保留 `ember-farm-before-alliance-v1`；v0.14.0–v0.24.0 没有新增存档键，只在存档里新增 `outpost`、`winter`、`seasons`、`far`、`daily`、`skills`、`theft`、`garden`、`gear`、`feel`、`undertow` 字段，偏好键里多存无障碍选项、改过的键位和四个音量（`audio`，不进存档）。v0.21.0 的新旧画面选择存在 `ember-farm-visual-v1`；v0.22.0 去掉了开关，这个键不再读也不再写，存的“原画面”会被忽略。设置中可导出当前家园或历史与恢复文件，并通过导入选择恢复检查点。旧版独立试玩槽位保持原字节，不会覆盖正式家园。

## 素材

画面里的地图、人物、感染者、防具和武器、建筑、物件、作物和光影都是代码画的原创像素画；音乐、环境声和音效都是代码合成的，包里没有音频文件；物品图标、动物和鸡窝由原图按调色板转成像素。标题、数字、按钮用的融合像素体是开源字体（SIL OFL 1.1，许可随包附在 `dist/fonts/OFL-fusion-pixel.txt`）。原来的 farm、ruins、sprites、expansion、frontier 像素素材还留在包里，物品图标和动物从它们转换；援建队员与灰隼团枪手由现有人物精灵重新着色并加画头饰；营地、终端、水槽、餐桌、出货箱、篷车、机床、运输骡与人物立绘为程序绘制像素图形。没有引入参考作品的原版素材。
