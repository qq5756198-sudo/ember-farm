# 余烬农场 v0.22.0「披挂」

单人中文 HTML/Canvas 末日经营游戏。十五张地图，农业供给、生产工程、远征收复、居民生活、防御战斗、调查复兴六种玩法共同推进家园重建。画面全部是代码画的原创像素画；前期感染者更凶，靠防具和各种武器活下来；统一高难度，浏览器本地保存。

原在线地址（v0.12.0）：https://ember-farm.qq5756198.chatgpt.site 。本仓库没有该站点的部署权限，v0.13.0 至 v0.22.0 都没有覆盖原地址。

## 本轮

按《前期感染者加强与装备防具方案》实施，五个待定项都按推荐做；种菜第二轮顺延到 v0.23.0。这一版同时去掉了新旧画面开关，只留新画面。

- **感染者变强，分三段**：第 1–3 天、第 4–7 天、第 8 天以后各一套血量、速度、伤害；废墟里三四只一群守着能搜的地方，一只发现你，同群的半秒后一起追；地区和边境地图也多了几只。农场的尸潮还按原来的规则。
- **八种新行为，都先给预兆**：被围时会被抓住（推开或连按挣开）、奔跑者伏低后扑人、尖叫者叫来新的、重甲跺脚后冲撞、听到声音过来找、夜里更凶、残血的摔成爬行者伸手咬脚踝。
- **人这边**：新增推开（X，10 体力），挨打后不受伤的时间缩短到 0.45 秒，绷带和药包改成几秒内慢慢回血，抓伤会流血；被咬涨感染，满了发烧（生命上限 70、体力恢复减半），药包加一晚睡眠退烧，不会因为被咬死掉。
- **装备**：头、身、手、腿、脚五个防具栏，近战、远程、投掷三个武器栏，外加陷阱；19 件防具、20 种武器。全身护甲最多 50%；伤口落在哪一处就看那一处的防抓、防咬；穿得越重越慢、越响。穿上的装备画在人物身上。
- **耐久、修理、改装、图纸**：装备会磨损，坏了没有保护、武器伤害减半，但不会消失；在武器台修（每修一次上限少 10%，修 5 次只能拆），也能改装、拆解、换上备用的；7 张图纸从废墟、商队、偷盗宝贝和每日抉择里拿。死在外面时身上每件装备耐久 −25%。
- **界面**：穿戴在背包（Tab）的装备栏，修理改装在武器台“武器与潜行 · 修理改装”那一页，没有加新面板；快捷栏 4 近战、5 远程（再按一次 5 换下一把）、6 投掷、7 陷阱；被抓、流血、感染、发烧显示在顶栏下面。
- **旧档**：不重置；手上的木棍、枪、保温衣自动装上，补一副破布护手和一双布鞋；过了第 3 天的档有 3 天缓冲，仓库里送一套旧衣服。

详见 [docs/releases/v0.22.0.md](docs/releases/v0.22.0.md)。上一轮（新画面）见 [docs/releases/v0.21.0.md](docs/releases/v0.21.0.md)。

标题页提供继续游戏、开始新游戏、设置、制作人员。版本号显示在标题页角落与设置底部。

## 运行

无需构建。用 HTTP 服务打开（不要用 file:// 双击）：

    python3 -m http.server 8000 --directory dist

然后访问 http://localhost:8000 。

## 验证

- `npm test`：627 项游戏、存档、迁移、故事、前哨、寒潮、四季、远方、每日抉择、妙手、种菜、画面与装备检查（画面检查要 `@napi-rs/canvas`，没装时自动跳过）。
- `npm run test:ui`：实际 game.js 控制器 + DOM 替身 + 原生 Canvas（需先 `npm install --no-save @napi-rs/canvas@0.1.100`）。不等同浏览器 CSS 验收。
- `npm run sim:gear`：用正式代码让机器人出门搜刮，看死亡率和一场仗多久；`node scripts/gear-sim.mjs 次数 天数 地图 打法` 跑别的组合（用法写在脚本开头）。
- 本轮另用无头 Chromium 检查了装备栏、武器台、预兆、夜里、色弱与减少闪烁（1366×768、1920×1080、390×844 触屏）；真机与其他浏览器仍待验证。完整清单见 [docs/ITERATION-LEDGER.md](docs/ITERATION-LEDGER.md)。

## 操作

WASD/方向键移动，E 交互（几样东西挨在一起时先选，数字键快选；在田边按 E 依次是收获、拔草、捉虫、开垦、浇水、照看，空田是选种；被抓住时连按 E 挣开，爬行者跟前按 E 踩），X 推开（被抓住时立刻挣开），V 蹲行（蹲着靠近人按 E 下手，小游戏里空格抽、Esc 收手），K 技能页，左键使用工具或攻击，Tab 背包与装备栏，快捷栏 4 近战、5 远程（再按 5 换下一把）、6 投掷、7 陷阱，C 制作，B 建造，M 地图，J 任务手记，F 远征途中选下一站，L 消息记录，Z 防线视图，Esc 设置。按键可在设置里改（字母键），也支持手柄（LT 推开、RT 跑步）。触屏提供摇杆和使用/交互/推开按钮，窄屏右上角“☰ 菜单”打开快捷页。菜单打开及页面关闭时，世界暂停。

## 保存

正式键 `ember-farm-save-v1`，备用键 `ember-farm-backup-v1`，设置键 `ember-farm-preferences-v1`。新游戏和导入分别保留 `ember-farm-before-new-v1`、`ember-farm-before-import-v1` 检查点；旧档第一次升级到 v0.13.0 及以后版本前保留 `ember-farm-before-alliance-v1`；v0.14.0–v0.22.0 没有新增存档键，只在存档里新增 `outpost`、`winter`、`seasons`、`far`、`daily`、`skills`、`theft`、`garden`、`gear` 字段，偏好键里多存无障碍选项与改过的键位。v0.21.0 的新旧画面选择存在 `ember-farm-visual-v1`；v0.22.0 去掉了开关，这个键不再读也不再写，存的“原画面”会被忽略。设置中可导出当前家园或历史与恢复文件，并通过导入选择恢复检查点。旧版独立试玩槽位保持原字节，不会覆盖正式家园。

## 素材

画面里的地图、人物、感染者、防具和武器、建筑、物件、作物和光影都是代码画的原创像素画；物品图标、动物和鸡窝由原图按调色板转成像素。标题、数字、按钮用的融合像素体是开源字体（SIL OFL 1.1，许可随包附在 `dist/fonts/OFL-fusion-pixel.txt`）。原来的 farm、ruins、sprites、expansion、frontier 像素素材还留在包里，物品图标和动物从它们转换；援建队员与灰隼团枪手由现有人物精灵重新着色并加画头饰；营地、终端、水槽、餐桌、出货箱、篷车、机床、运输骡与人物立绘为程序绘制像素图形。没有引入参考作品的原版素材。
