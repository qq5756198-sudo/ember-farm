# 余烬农场 v0.25.0「长夜」

单人中文 HTML/Canvas 末日经营游戏。十五张地图，农业供给、生产工程、远征收复、居民生活、防御战斗、调查复兴六种玩法共同推进家园重建。画面全部是代码画的原创像素画，声音和音乐也全部是代码合成的；前期感染者更凶，靠防具、各种武器和翻滚活下来；废墟里每天亮的柜子、摆法和小事件都不一样，第 4 天起有新感染者和头目；主线打完以后每 7 天一个越来越大的长夜、灰隼团的反扑，新开一局可以选出身、打完可以带着记忆开二周目；统一高难度，浏览器本地保存。

原在线地址（v0.12.0）：https://ember-farm.qq5756198.chatgpt.site 。本仓库没有该站点的部署权限，v0.13.0 至 v0.25.0 都没有覆盖原地址。

## 本轮

按《手感、惊喜与节奏改造方案》做第三版，也是最后一版（v0.23.0「回响」做了声音、打击感、翻滚、少打断和开局，v0.24.0「暗涌」做了搜东西随机、新感染者和头目）；种菜第二轮顺延到 v0.26.0。

- **长夜**：主线打完以后，每 7 天（和节庆错开 3 天）一个长夜：08:00 日期变红，18:00 天边发红、打雷，22:00 一声尖叫，尸潮分三波来农场，第三波有头目；守到 04:00 天亮就算守住。每守住一个，下一个多两成（最多一倍）；守住给金币和稀有掉落，第 1、5、10 个给纪念品（档案馆第七个展柜）；守满 10 个，档案岛播出最后一段广播，弹结局卡“余烬地区收复”。
- **灰隼团反扑**：主线打完后第 5 天废墟里有两个探子（打倒拿到他们的地图），第 7 天夜里有人摸进农场埋东西，第 10 天头领“隼头”带人来——有枪、扔烟雾弹，他倒下剩下的就跑。
- **出身**：开始新游戏时选：种地的（原来的开局）、卫生员、猎人、机修工、退伍兵，各带几样东西、一两条好处和代价。
- **二周目**：主线打完后设置里“带着记忆重新开始”：带学会的图纸、成就册、生涯记录和一件装备，原来的家园先存一份，可以恢复。
- **打磨**：147 个物品小图和鸡、山羊、羊、麦穗都按新画法重画；载入快了（无头浏览器里能点“继续游戏”从 2.0–2.4 秒到 1.3–1.9 秒），别的地图在后台先画好，第一次进图不再停一下；超过 7 天没导出存档会提醒一次，设置里写着上次导出是哪天。

详见 [docs/releases/v0.25.0.md](docs/releases/v0.25.0.md)。前两版见 [docs/releases/v0.24.0.md](docs/releases/v0.24.0.md)、[docs/releases/v0.23.0.md](docs/releases/v0.23.0.md)。

标题页提供继续游戏、开始新游戏、设置、制作人员。版本号显示在标题页角落与设置底部。

## 运行

无需构建。用 HTTP 服务打开（不要用 file:// 双击）：

    python3 -m http.server 8000 --directory dist

然后访问 http://localhost:8000 。

- `npm test`：738 项游戏、存档、迁移、故事、前哨、寒潮、四季、远方、每日抉择、妙手、种菜、画面、装备、手感、声音、暗涌、长夜与载入检查（画面检查要 `@napi-rs/canvas`，没装时自动跳过）。
- `npm run test:ui`：实际 game.js 控制器 + DOM 替身 + 原生 Canvas（需先 `npm install --no-save @napi-rs/canvas@0.1.100`）。不等同浏览器 CSS 验收。
- `npm run sim:gear`：用正式代码让机器人出门搜刮，看死亡率和一场仗多久；`node scripts/gear-sim.mjs 次数 天数 地图 打法` 跑别的组合，加 `ROLL=telegraph` 或 `ROLL=crowd` 让机器人翻滚；地图写 `longnight` 守长夜（`LNPREP=1` 备过战的农场、`LNHELD=4` 之前守住过几个），`ORIGIN=medic` 加打法 `start` 看各个出身的前三天（用法写在脚本开头）。
- `npm run sim:loot`：搜东西随机以后每趟平均拿到的和以前比；`npm run sim:boss`：头目战的胜率、死亡率和一场多久（用法都写在脚本开头）。
- `node scripts/modulepreload.mjs`：加了或删了模块以后重新生成 index.html 里的 modulepreload 列表（测试会检查它和实际 import 的一致）。
- 本轮另用无头 Chromium 检查了选出身、长夜一整晚（红日期、红天、三波、头目血条、天亮的战报和“睡到早上 8 点”）、结局卡、导出提醒、设置里的二周目、灰隼团头领和烟雾、摸进来的人，以及载入时间、第一次进每张图的那一帧和夜里暴雨的帧数（1366×768、1920×1080、390×844 触屏、844×390 横屏触屏）；真机与其他浏览器仍待验证。完整清单见 [docs/ITERATION-LEDGER.md](docs/ITERATION-LEDGER.md)。

## 操作

WASD/方向键移动，Shift 跑步，空格翻滚，E 交互（几样东西挨在一起时先选，数字键快选；在田边按 E 依次是收获、拔草、捉虫、开垦、浇水、照看，空田是选种；被抓住时连按 E 挣开，爬行者和地上装死的跟前按 E 踩，锁着的柜子前按 E 撬、再按一下停），X 推开（被抓住时立刻挣开），V 蹲行（蹲着靠近人按 E 下手，小游戏里空格抽、Esc 收手），K 技能页，左键使用工具或攻击，Tab 背包与装备栏（按住是轮盘），快捷栏 4 近战、5 远程（再按 5 换下一把）、6 投掷、7 陷阱，C 制作，B 建造，M 地图，J 任务手记，F 远征途中选下一站，L 消息记录，Z 防线视图，Esc 设置。按键可在设置里改（字母键），也支持手柄（LT 推开、RT 跑步、B 翻滚）。触屏提供摇杆和翻滚/使用/交互/推开按钮，窄屏右上角“☰ 菜单”打开快捷页（拍照在这里）。菜单打开及页面关闭时，世界暂停。

## 保存

正式键 `ember-farm-save-v1`，备用键 `ember-farm-backup-v1`，设置键 `ember-farm-preferences-v1`。新游戏和导入分别保留 `ember-farm-before-new-v1`、`ember-farm-before-import-v1` 检查点；旧档第一次升级到 v0.13.0 及以后版本前保留 `ember-farm-before-alliance-v1`；v0.14.0–v0.25.0 没有新增存档键，只在存档里新增 `outpost`、`winter`、`seasons`、`far`、`daily`、`skills`、`theft`、`garden`、`gear`、`feel`、`undertow`、`longnight` 字段，偏好键里多存无障碍选项、改过的键位和四个音量（`audio`，不进存档）。v0.21.0 的新旧画面选择存在 `ember-farm-visual-v1`；v0.22.0 去掉了开关，这个键不再读也不再写，存的“原画面”会被忽略。设置中可导出当前家园或历史与恢复文件，并通过导入选择恢复检查点。旧版独立试玩槽位保持原字节，不会覆盖正式家园。

## 素材

画面里的地图、人物、感染者、防具和武器、建筑、物件、作物、物品图标、动物和光影都是代码画的原创像素画（物品图标和动物从 v0.25.0 起）；音乐、环境声和音效都是代码合成的，包里没有音频文件；少数扩建物件仍由原图按调色板转成像素。标题、数字、按钮用的融合像素体是开源字体（SIL OFL 1.1，许可随包附在 `dist/fonts/OFL-fusion-pixel.txt`）。原来的 farm、ruins、sprites、expansion、frontier 像素素材还留在包里，少数扩建物件从它们转换；援建队员与灰隼团枪手由现有人物精灵重新着色并加画头饰；营地、终端、水槽、餐桌、出货箱、篷车、机床、运输骡与人物立绘为程序绘制像素图形。没有引入参考作品的原版素材。
