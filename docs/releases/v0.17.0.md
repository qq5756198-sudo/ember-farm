# v0.17.0「远方来客」

基线：v0.16.0「前哨四季」。日期：2026-10-07。按扩展设计方案中标为 v0.17 的 9 项实施（3 项玩法、2 位人物、4 项界面），同时处理 v0.16.0 记下的三条已知限制。

保留 HTML/Canvas、像素素材、十五张地图、六大玩法与玩家存档；统一高难度，没有难度选择。没有新增独立管理面板：夜里的事、险地、补救、雨巷和垫付都挂在任务手记里，麦穗有自己的一页，彭姐和贺满仓在场景里按 E 对话。

第三段之后开放夜里的抉择与今日险地；第四段起彭姐来借粮；第八段完成后贺满仓到前哨。已经走到后面段落的旧档读入后直接开放。

## 三项玩法

### 夜里的抉择

- **时间与地点**：每晚 19:00 起，废弃居民区、旧医院、工业仓库中已开通的一处会有一件事，凌晨 05:00 前有效。任务手记写明在哪，可以一键标出位置。
- **三种事**，各有三个选择，每个选择都写清花费、得到和影响：

  | 事 | 选择 | 结果 |
  |---|---|---|
  | 有人住的废墟 | 全拿走 | 干粮 3、布料 2、零件 1；营地声望 −3，居民士气 −2；之后可以还回去补救 |
  |  | 什么也不动 | 声望 +1；两天后这家人送来药草种子 |
  |  | 留下两份干粮 | 声望 +2，士气 +3；三天后送来一个药包 |
  | 受伤的陌生人 | 给他包扎（绷带 1） | 声望 +2；他第二天上午到营门想留下（只会来一次，之后的伤者改送谢礼） |
  |  | 背回营地（药包 1） | 声望 +3，士气 +2；同上 |
  |  | 走开 | 士气 −2；第二晚他还在原地，可以回去找他 |
  | 别营地的储藏 | 全拿走 | 弹药 12、零件 2、干粮 4；声望 −4，彭姐关系 −2；之后可以赔礼 |
  |  | 拿一半，留欠条 | 弹药 6、零件 1、干粮 2；声望 −1；欠条之后能还 |
  |  | 把锁绑好，原样留下 | 声望 +2，彭姐关系 +2 |

- **补救**：拿走的东西、欠条和赔礼都留在任务手记的“补救”行，东西够了点一下就还，声望和关系补回来。
- 一晚只能定一次；回礼按唯一记录发放，读档或重复点击都不会多拿。
- 地点和事的种类每天单独决定，不会固定在同一片废墟。

### 今日险地

- 每天 06:00 定下当天的险地（三片废墟中的一处），20:00 预告明天的。任务手记写明风险与能拿到的东西。
- **三种情况**：

  | 情况 | 风险 | 能拿到 |
  |---|---|---|
  | 浓雾 | 画面起雾，只看得清身边；开箱会惊动附近 2 只感染者 | 废金属 4、布料 2 |
  | 尸群迁徙 | 一进去就多 4 只感染者，打完才能开补给 | 弹药 10、零件 2 |
  | 物资漂来 | 18:00 前不去，东西就被冲走 | 干粮 4、食盐 2、松脂 2 |

- 每天只能开一次；地图上在那片废墟旁标出“今日险地”。

### 麦穗的本事

- 每天喂一份干粮、摸摸它、带它出一趟远门（农场和集市以外的地方），各加 1 点默契，上限 15。
- **四项本事**：

  | 默契 | 本事 |
  |---|---|
  | 3 | 刨种子：隔天清晨在农场刨出 2 颗种子 |
  | 6 | 看护鸡舍：有鸡舍时每天多 1 个鸡蛋 |
  | 9 | 提前吠叫：尸潮和灰隼团的预警多 20 秒 |
  | 12 | 叼回背包：你倒在外面时，第二天清晨它把遗落的背包叼回仓库 |

- 麦穗页显示默契条、今天喂过 / 摸过 / 一起出门没有，以及已学会和未学会的本事；处理过雾松林场的“狗在桥前停住了”后，还能在这一页下指令（跟着、警戒、原地等、回家）。

## 两位人物

| 人物 | 出场 | 故事与能力 |
|---|---|---|
| 彭姐 | 第四段起，08:00 到农场东边 | 雨巷营地的首领，来借六份干粮。可以借六份、只借三份或不借。三天后雨巷被尸群围住，孩子来求援，限两天：去雨巷住区打退 5 只感染者，或托孩子带回弹药 12、绷带 2。帮了忙就能签互助合同：每 7 天轮流供 6 份干粮，灰隼团来时防守力 +2，尸潮时她的人帮忙打掉 2 只；轮到前哨时交不出，关系会变差。不签就每周做一次买卖。没去救，雨巷散了，过几天她重新落脚，每周来卖弹药和零件 |
| 贺满仓 | 第八段完成后，农舍北边的账桌 | 联盟账房，只看账本：出货结算过 3 次、交过 2 份援建清单，他才肯垫付。之后建造菜单里材料不够的设施会多一个“贺满仓垫付”按钮：先建，再分三期还，不收利息；一次只能欠一笔，还清后可以再借。蓝图、奖杯等原有建造条件照旧 |

## 四项界面升级

- **金色路径与屏幕边缘箭头**：标了目标后，场景里从脚下到目标画一条沿路走的金色虚线；目标在屏幕外时，屏幕边缘有指向它的箭头和步数。事情办完（做了决定、开了补给、答复了彭姐）路标自动撤下。
- **移动端快捷菜单**：窄屏（1100 像素以下）右上角的“设置”换成“☰ 菜单”，一页大图标：任务手记、背包、制作、建造、地图、日历、人物、法令、麦穗、出货、消息、设置。
- **无障碍选项**（设置页，存进偏好）：
  - 大号文字：菜单、提示条、警报和当前目标放大到 130%；
  - 色弱友好配色：危险、提醒、完成改用蓝、橙、白，并加 ▲ ● 符号；
  - 减少闪烁与震屏：开枪和受击不晃镜头，界面动画停下，加工站故障牌不再闪。
- **键位自定义与手柄**：
  - 设置页列出 17 个动作的按键，点“改键”后按一个字母键；两个动作选同一个键时互换；N、F、K、方向键、Tab、数字键、空格、Shift、Esc 不能改；可以恢复默认。交互提示和菜单页脚跟着显示新键。
  - 手柄（浏览器标准映射）：左摇杆 / 十字键移动，A 交互或确认，B 返回或取消建造，X 使用工具（自动瞄准最近的感染者），Y 背包，LB/RB 切换快捷栏，右摇杆朝向，Start 设置，Back 任务手记；菜单里十字键移动焦点。设置页显示是否检测到手柄。

## 处理的已知限制

- **灰隼团会打营地的人和围栏**：枪手看不见你、或有三成概率转而瞄准 340 步内的居民、援建队员、围栏、大门或瞭望塔。流弹擦伤居民（疲劳 +15、士气 −4）、让队员挂彩回帐篷歇着，打掉设施 6 点耐久。战报写出擦伤几次。
- **援建队员干活有动作**：维修时挥锤、站岗时端枪、吃饭时捧碗冒热气、休息时冒“z”、饿着时发抖，搬运时抱着箱子。仍是同一套人物精灵加叠层，不是新画的动作帧。
- **出货价每天浮动**：每样东西每天在 ±18% 内变动，出货页写“今日行情 ↑/↓”；按放进箱子那天的行情结算。

## 待验证

1. **真手柄**：手柄只用模拟的浏览器接口测过，真机（Xbox、PlayStation、Switch Pro）在不同浏览器下的按键映射、断开重连还没试。

## 已知限制

- 改键只改键盘；提示条和部分场景文字（例如“Z 键查看防线”“营火 · 夜谈（E）”）仍写默认键。
- 只能改成字母键。
- 灰隼团只打围栏、大门、瞭望塔这三种设施；不在农场时仍用公式结算。
- 没修通雨巷住区的入口时，只能托孩子带东西回去，不能亲自解围。
- 援建队员的动作是叠在原精灵上的小动画，不是新画的动作帧。
