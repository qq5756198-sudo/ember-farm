## 先这样试玩

1. 首页选择“试玩营地回响 · 20事件”。这是独立中后期营地，有三名居民与有限补给，正式家园和第一章试玩不会被覆盖。普通继续游戏则按已有建设与故事逐步解锁事件。
2. 事件中心先接“封路的粮食车队”，选择修车，点击“装够本步材料”，标记现场并前往住宅区。沿金色编号找到现场，投入6木材和2零件，关闭菜单推进45游戏分钟，再回营完成交接。
3. 在“事件留下的服务与改装”交付3干粮，换回种子或金属。种植、加工与救援的后续用途可直接体验。每日只能选一次车队交换。
4. 再接“陈工的满负荷测试”，加工并领取3份新干粮，选择四条供给计划或12次无人机维护周期；已持有的旧干粮不能直接完成生产考核。
5. 接“防线盲点演习”，准备弹药、料理与守卫岗位后开战。查看塔楼、陷阱、减伤和损坏位置。倒下后先恢复，再回事件原步骤重试，已支付材料不重复扣除。
6. 体验“返航无人机的最后信号”，先选两箱，剩下的可实地重访取回；首次回营解锁行囊+2格。需要退出试玩时，从设置返回正式进度。

WASD移动、E附近交互、N/F六大玩法、M地图、H相机。菜单和离线均暂停世界；等待按游戏分钟，不按现实时间。可延期尚未开工的事件；同时最多两件。

## 本轮修复的具体问题

- 提前在另一个地区查看事件时，标记可能落在障碍物中；现在进入实际地区时重新检查可达落点。
- 事件战斗跨天而玩家暂离后，废墟刷新会删除敌人；现在保留正在进行的事件敌群。
- 普通尸潮可能与演习叠加；事件战斗期间推迟普通尸潮，倒下后给恢复窗口。
- 背包满时敌人原量掉落可能绕过减产；地面掉落也先应用同样的数量规则。
- 早熟棉种奖励使用了不存在的特性名称；已统一为现有early基因，完成后可保存恢复。
- 改装四条调度可能遗留超限在制批次或无人机磨损；现在先校验批次，转换磨损上限并立即验证读档。
- 现场寄存箱领取后仍残留显示对象；现在刷新场景，重复领取不再生效。
- 居民日报最初漏掉人物特长补种和制药；已纳入实际物资变动。
- 重复事件不会重复增加永久容量；服务冷却、已付款步骤和失败重试状态随存档保留。
