# v0.21.0「新颜」

基线：v0.20.0「一亩田」。日期：2026-10-10。按《余烬农场 · 画面大改造方案》实施。

方案原定分三轮：

- v0.21.0：农场定稿、全局光影天气、人物和感染者、界面；
- v0.23.0：四个废墟区；
- v0.24.0：五个地区和五张边境地图。

玩家要求一次全部改完，这一版就把十五张地图、所有人物和感染者、建筑和物件、光影天气、全部界面和物品图标都换成了新画法。

方案里七个待定项玩家没有改，都按推荐做：

- 按农场样张的方向全面铺开；
- 夜里亮度保持样张的样子（探索地图另见“和方案不一样”）；
- 像素字只用在标题、数字和按钮上，正文字体不变；
- 农场布局不动；
- 缺水图标画在每块要浇水的田上；
- 设置里留新旧画面开关，留一个版本；
- 种菜第二轮顺延到 v0.22.0。

保留 HTML/Canvas、十五张地图的布局与碰撞、六大玩法和玩家存档，统一高难度。玩法和数值都没有改。

## 光影和天气

- **一天四段**：清晨、白天、黄昏、夜里，整个画面乘上当时的环境色，不再只是压一层蓝。
- **灯火**：
  - 窗户、门灯、路灯、串灯、霓虹招牌、信号灯、地底的灯管、补光灯、火桶、篝火灶、火炉、余烬，夜里都会发光；
  - 光是一圈一圈的像素色阶；
  - 边境修好的地点夜里会亮。
- **自己身边的光**：
  - 自己身边总有一小圈光；
  - 在外面探索的地图夜里更暗，带着手电筒照得更远。
- **雨**：
  - 小雨、暴雨、酸雨三种；酸雨是黄绿色，落地冒小烟；
  - 落地有水花；下雨时地上慢慢积起水洼，雨停后慢慢变干；
  - 暴雨有闪电，还有一层层飘过的雾；
  - 雨丝不落在人和感染者身上，攻击前的提示看得清。
- **各张地图的天气习惯**：
  - 白霜气象站的雨落下来是雪，有小雪、大雪；
  - 雾松林场常年有薄雾；
  - 雨巷住区总是湿的；
  - 地底避难城在室内：没有天气，灯一直亮着，空中飘着灰。
- **高温**：画面泛白，底图有热浪扭动，空中有浮尘。
- **粒子**：
  - 烟囱的烟、火星；
  - 夜里草地上的萤火虫，白天飘落的树叶；
  - 走路扬起的土（雪地上是雪沫），浇水的水花。
- **无障碍**：
  - “减少闪烁”打开时没有闪电，萤火虫不闪，雨雪更少、不左右晃；
  - 色弱配色的颜色在画面里保留：蓝、橙、偷盗时的眼睛、瞄准线。

## 界面

- **木头和锈铁的样子**：
  - 顶栏、底栏是木纹，页面有锈铁边框；
  - 按钮是方角，带立体边；
  - 生命、体力、饥饿是分格的像素条，颜色取自调色板。
- **字体**：
  - 标题、数字、按钮用融合像素体，开源字体，许可随包附在 `dist/fonts/OFL-fusion-pixel.txt`；
  - 正文字体不变；
  - 窄屏上顶栏的像素字自动变小。
- **颜色**：
  - 原来的绿色系换成调色板里的木头、锈铁和稻草色；
  - 选中、危险、警告、当前、完成这些状态，谁盖谁和原来一样；
  - 色弱配色照常生效。
- **其他**：
  - 物品格子里的图标是像素版；
  - 世界地图换成旧纸地图的颜色。
- **夜里也看得清的东西**：场景里的字（名字、提示、飘字）、交互圈、建造虚影、准星、田里的状态标记都在光照之后画。
- **镜头**：像素按整数倍放大，避免一格大一格小；差得太多时用原来的缩放，“场景缩放”设置照样有效。

## 新旧画面开关

- 位置：设置 → 画面风格，“新画面 / 原画面”，标题页也能切。
- 只换画面，不动存档。选择存在单独的键 `ember-farm-visual-v1` 里，刷新后还记得。
- 原画面和 v0.20.0 一样：独立检查逐像素对比了 21 个画面场景，完全一致；13 个页面除了版本号都一样。
- 样张里左上角的“画面样张”预览条和“一键摆成型农场”都去掉了，没有进正式版。

## 和方案不一样

- **物品图标、动物和鸡窝**：是把原图按调色板转成像素，没有逐个重画。
- **探索地图的夜色**：在外面探索时，夜里比农场暗，环境色再压 25%，手电筒照得更远。这样保留了原来夜里探索靠手电的玩法。
- **等待时间**：
  - 第一次进某张地图要先画底图，会停 0.2–0.4 秒；
  - 载入页比原画面多停约 0.7 秒，因为先把当前地图画好了。
- **检疫科研园**：下面三处原来画成玻璃温室，人会从房子里穿过去，改成了平的试验田（原来的画法也是试验田）。
- **树**：雾松林场、白霜气象站空地上的树比样张稀；交互点和出口上方不种树。
- **镜头**：按整数倍放大时，镜头位置会有一点点吸附。
- **分轮**：方案原定分三轮，这一版一次做完。

    - 像素图集排布不变；
    - 开关只写自己的键，不碰存档。
  - 控制器检查全部通过。

  - 十五张地图都截了白天、夜里、暴雨的图，视口有 1366×768、1920×1080、683×384@2x（相当于 200% 缩放）；

  - 390×844、360×740 下顶栏不溢出。
- **界面颜色巡检**：
  - 21 个页面在 1366 和 200% 缩放下都没有残留的旧绿色；
  - 带状态的元素在新画面里都和旁边的不一样。
- **独立审查两轮**：
  - 第一轮发现 4 个严重问题、6 个中等问题和十来个小问题，都已修好。主要问题：
    - 溪谷种植位的编号是字符串，画面里算出 NaN；
    - 新界面盖住了选中、危险、警告等状态颜色；
    - 标题页上切换画面没有反应；
    - 检疫科研园的温室画在能走的地上；
    - 田里的状态标记和准星夜里发暗；
    - 边境修好的地点不亮，渡船和清理过的河看不出来；
    - 松林空地太密，树冠盖住医院出口；
    - 启动和下雨时太费；
    - 同一个人换了活计，衣服不变。
  - 第二轮逐条复核：都已修好，没有发现新问题，原画面和 v0.20.0 逐像素一致；性能只解决了一部分，见下面。
