# 余烬农场 · 持续完善清单

当前交付：**v0.6.0「供给与远行」**。基线：v0.5.0「重建之路」。更新日期：2026-10-06。

本清单以实际源码、自动化运行和控制器检查为依据。没有取得新的真人试玩录像或逐条反馈；“用途不清”的判断来自已有反馈与代码中的目标、队列、合作等级实现。不能据此认定长期留存或平衡已经成熟。

## 本轮实际完成

1. 目标备料：主线自动拆出当前应做的工程、设施、配方或研究；也能钉住合同、居民愿望或地区建设。显示已有、缺口、在制、获取方式与产出用途。多步加工计算会抵扣共享原料并复用一批产出的余量。前哨材料显示随身数量，可从仓库装到所需数量。
2. 供给计划：集市第一阶段和制作台启用调度。九种已有配方可设置1–30份仓库目标，最多三条同时运行，每条同时一批。普通和耐旱原料从仓库预付，成品自动入仓。可设置原料底线，暂停补货、取消并退款；手动成品也能直接入仓。随身物资和优质作物不会被自动加工拿走。
3. 地区合作：三处前哨各有两种支援方向。完成该地区2、5、9份合同后，再投入材料建设协作站、地区工坊、复兴枢纽。以后的每份合同额外送回所选物资的1、2、3倍，前哨显示对应补给设施；免费切换方向只影响后续交付。

本轮连通的实际循环：收成入仓 → 干粮或医疗加工 → 工作餐与居民劳动 / 前哨合同 → 地区建设 → 种子、材料或战备回程支援 → 下一轮种植、生产和远征。所有节点均有真实资源变动，关闭网页不会推进生产。

## 待验证 · 明确边界

- 当前环境没有受支持的真实浏览器控制技能，本轮未启动浏览器预览。桌面两种尺寸的完整页面点击、触屏误触、菜单遮挡滚动、200%缩放、中文系统字体均待真实浏览器验证。
- 原生Canvas环境缺少中文字体，画布文字显示不能作为中文可读性验收；文字内容由UI生成和控制器检查覆盖。
- 尚未证明真人完整四章耗时、地区9单目标的重复感、三条补货计划的长期平衡、各种防线在真实操作中的难度；没有把自动化战斗夹具当作真人难度测试。
- 农田旧存档只标记“扩建农田”，不能区分当年奖励与玩家自建来源；迁移以现存扩建数量抵扣已交付数，保留所有现有地块，优先避免重复赠地。
- 六条主线相关系统均已检查，但没有宣称全部支线玩法已达到最终设计质量。

## 本轮试玩路线

1. 在原地址继续游戏，确认顶部显示v0.6.0。旧正式进度和v5章节试玩均沿用原保存位置。
2. N/F→当前目标，查看“下一步”和缺料来源。新角色先完成两株收成、加工一批干粮、接回阿禾并建好公共餐桌与制作台。
3. 生产工程设置干粮目标6份，将萝卜存入仓库；设置保留3份萝卜。关闭菜单去种植，回来观察已入仓干粮、居民工作餐与暂停投料原因。
4. 选择布料和绷带两条计划，存入棉花，观察布料成为绷带原料；钉住诊所或医院合同，备料表会随库存变化。
5. 医疗通道守住后完成同一地区两单合同，投入施工材料建协作站。选择工程/生产或生活/远征支援，交付下一单查看实际回程物资。5、9单提供后续建设目标。

## 借鉴出处与适配

- [异星工厂官方Wiki：电路网络教程](https://wiki.factorio.com/Tutorial:Circuit_network_cookbook)：按容器库存限制输入。本作改为玩家设置有限库存目标，统计成品与在制品，达到目标即停止补料；没有复制其电路搭建复杂度。
- [风暴之城开发者：Logistics and Balance Update](https://eremitegames.com/logistics-and-balance-update/)：仓库最低库存保护制造用料，运输分工连接仓库与生产。本作原料底线只限制新增的自动加工，手动操作仍由玩家决定；利用已有仓库和制作设施，不增加一整套运输建筑。
- [Raph Koster：Geek Fun Isn’t Frivolous](https://www.raphkoster.com/games/essays/geek-fun-isnt-frivolous/)：从学习与掌握规则解释乐趣，指出单一解法被掌握后会削弱趣味。本轮据此提出的设计判断是让玩家从亲手加工转向安排有限产线，再按当前经营/出行需要改变回程支援；这属于本作的适配判断，不是已经验证的留存结论。
