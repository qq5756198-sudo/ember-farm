# v0.13.0「联盟来信」

基线：v0.12.0「路与目标」。日期：2026-10-06。按已批准的《余烬农场：联盟前哨》方案实施第一轮。

保留 HTML/Canvas、像素素材、十五张地图、六大玩法、统一高难度和玩家存档。没有难度选择，没有再次放大资源压力，没有新增独立管理面板。

## 故事接入

- 农场留言板旁接入**联盟终端**。新档开局收到楚光的来信（小柒转达）；旧档以“联络站接通了旧终端”接入。
- **第一段「收到回信」**：收获两株作物 → 做出第一份干粮 → 修好水井的辘轳和水槽（石材 3、废金属 2）→ 搭起援建营地（木材 4、石材 2）→ 到联盟终端回信。作物生长或干粮在灶上时，任务自动指向附近的水井或营地，等待时间有事可做。
- **第二段「今天吃饭的人」**：选定第一批援建物资（口粮种包或棉花种包，只能选一）→ 接回阿禾与种子档案 → 让阿禾吃上工作餐 → 让公共餐桌有灯光。完成后联盟记下“前哨供粮合格”（40 金币、营地声望 +5），住宅区开放邻里互助点，第三封信引向医院求援。
- 收成、干粮、阿禾、公共餐桌仍是原主线的四个节点，判定和奖励不变，不重复计算。

## 援建队员「铁锹」（搬运）

- 回信后抵达，住援建营地的帐篷。每天吃 1 份干粮（先取仓库，人在农场时也可取背包）；没吃上时干活减半，小柒每天提醒一次。
- 白天每个钟点做一件搬运，按顺序：做好的加工成品入仓（计入产出记录）→ 农场上散落的物资入仓 → 清走田里的杂物（按现行稀缺规则入仓，并翻好那块地）。夜里回帐篷休息，饭点到公共餐桌或火盆边吃饭。
- 场景中可见：橙色工装与安全帽，搬箱走动，头顶显示正在做的事；按 E 和他说话会显示累计搬运次数。走动中的他不会抢走农田或设施的 E 交互。

## 统一任务入口

- 任务手记主卡改为三行：**发生了什么 / 现在做什么 / 完成后获得什么**，本段进度用一行标签显示。默认按钮“标记地点”；有加工需求时“准备物资”只打开对应配方，不越过材料确认。
- 原主线十六个节点也用同样的三行卡，每个节点补了一句处境说明。
- 不需要实物交付的主线节点，条件达成且人在农场时直接记录进展，不再多点一次领奖。需要交付物品的节点（例如医疗补给）仍要玩家确认。
- 来信与前哨记录收在任务手记的折叠区。终端有新信或可以回信时闪灯，站在旁边的居民不会挡住终端。目标完成后自动撤下金色路标。
- 本地地图新增联盟终端、援建营地、邻里互助点地标。

## 场景变化

修好的水井辘轳与通往第一排田的木水槽（每天清晨放水）；联盟终端；援建营地（帐篷、火盆、木墩、识别旗，夜里有火光）；公共餐桌（集市第一阶段后出现，主线“公共餐桌”完成后点灯）；饭点的用餐者和碗；废弃居民区的邻里互助点（每天一次：干粮 1 → 木材 3、萝卜种子 2）。
