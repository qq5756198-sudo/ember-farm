# v0.11.0「边界之外」

基线：v0.10.0「归于生活」。日期：2026-10-06。发布地址：https://ember-farm.qq5756198.chatgpt.site

本轮保留 HTML/Canvas、像素美术、原十张地图与六大玩法。新增五张逐步解锁地图、40处场景交互、73个设施动作，以及20个新事件的42个选择分支。仍处于正式版产品化过程，未标记v1.0.0。统一高难度参数沿用原1.5倍体系，不再次全局放大，不提供难度选择。

## 玩家入口与成长路线

在原地址选择“继续游戏”，通过营地手册的“边境手册”或世界地图“边境与航路”进入。所有地图说明前置条件、入口所在地和实际材料。开发文档、参考出处和测试入口不进入游戏。

| 地区 | 从哪里进入 | 成长条件 | 主要用途 |
|---|---|---|---|
| 雾松林场 | 溪谷试验田 | 阿禾获救、溪谷开放 | 再生木材、松脂、刺藤缓行篱、居民林业协作 |
| 沉湾船坞 | 旧站商街 | 商街开放、旧桥修复 | 排水开路、食盐、两槽船只改装、邮件与货运 |
| 地底避难城 | 雨巷住区 | 许医生获救、医院前哨二级 | 通风、互锁气闸、滤材生产、床位与医院捷径 |
| 白霜气象站 | 北线货运站 | 陈工获救、供电研究、前三地任意两项关键服务 | 本地寒冷、背风设施、天气记录、黑麦种源与航向 |
| 余晖档案岛 | 沉湾船坞 | 旧主线结束、固定航线、山顶测向 | 新工艺、种源备份、污染治理、分批撤离与家园愿景 |

第一次推荐从林场开始：观察风标→采脂→在本区仓库取出→投入保温或覆脂滤材；再恢复船坞和地下服务，为气象站准备物资。成熟存档按已有成果直接获得开放条件，无需重做救援和主线。

## 新事件

12个一次性故事：多出来的一副碗筷、两地护送的最后一段路、失真的安全灯、没有地址的邮袋、读反的施工图、围墙上的异藤、戴手套的制图员、狗在桥前停住了、三个明天、河流没有说谎、边界会谈、最后一班渡船。

8个可重复事件：霜线将至、静风之后、两份相反的战报、屋顶露天电影、双向气闸、林地红线、白昼的空街、封条上的小字。

- 事件需要到实际地点行动，并消费对应资源；选择改变工时、奖励、战斗、服务或永久地区状态。
- 与原营地事件共享两件进行中上限。压力事件避开守家和休整日；可暂缓后继续已付材料的步骤。
- 事件进度、施工、运输、居民排班和选择均可保存。背包满不会丢失新增工程或事件的产出，物资放入当地仓库。
- 故事结束后保留服务：种源合同可交付、延期或结束；三天河道条约到期可再谈；三种愿景都可继续建设；撤离保留每批进度。

## 实际系统延伸

| 玩法 | 为什么用、投入与操作 | 产出及接下来的用途 |
|---|---|---|
| 农业供给 | 取得黑麦种源、播种浇水、育种留种；三片林选择择伐或清伐 | 黑麦+食盐制作御寒餐；松脂进入保温、修缆车和滤材工艺 |
| 生产工程 | 各设施列出材料、工时和作用，最多并行三项工作 | 排水改变可通行区域；滤材维护气闸与医院捷径；船只两槽改装改变运力和旅途恢复 |
| 远征收复 | 按已有救援、研究和建设开放入口；设备修好后缩短往返 | 带回确定获得的种源、文献与服务，反复经营与维护产生再次前往的理由 |
| 居民生活 | 柏岚加入原居民结构；真实床位、每日食物、疲劳和唯一岗位 | 驻站研究或随队省时；家庭需空床，邻里工作餐换实际木材 |
| 防御战斗 | 付物资核实战报或安排巡逻；浇灌缓行篱，使用狗警戒 | 下一轮真正改变来袭方向或减少2名敌人；围栏近旁敌人减速，记录战报 |
| 调查复兴 | 两证据核灯、实物测量造原型、农业/工程/生活档案依次整理 | 新滤材配方、种源恢复优惠、永久清水旁路、三期愿景与分批撤离 |

## 画面与界面

- 新地图使用独立地形素材和40种专用设施；旧区域增加地标、接触阴影与环境细节。
- 作物分阶段形态、工具动作、居民岗位道具、敌人攻击提示、作业设备动画。
- 雨滴避让建筑、寒区足迹、低浓度林雾、水面变化；灯光读取真实修复和电量状态。

- 独立边境面板、地区导航、明确工时与消耗、当地仓库与运输状态。常驻区仍只显示一个追踪目标。

20个视觉条目的逐项交付与边界见 `docs/development/v0.11.0-visual-audit.md`。旧烘焙背景的逐屋顶透明、完整人物动作图集、旧公共建筑四阶段画面及墙体材质打击反馈仍需后续美术深化，不作为本轮已完全重做的内容。

## 验证

- 自动化测试：338项通过，0失败。包括旧内容回归、20事件42分支、73设施动作、五入口可达、40交互点寻路、真实扣料、材料不足、背包满、重复操作、退款、失败续接、第四居民与旧存档迁移。
- 控制器：真实`game.js`在DOM替身中验证新旧菜单、正式开局收获→加工→修路循环、旧档恢复、40新增点位面板、居民和事件入口、仓库与队列操作；四种画布尺寸1366×600、1920×900、390×480、844×240。
- 原生Canvas：156帧，15地区、40点位、20事件布置、工具与作物阶段、昼夜天气；1366×768、1920×1080、390×844。专项断言检查排水状态、安全灯校正、反光标与缺电灯光。
- 未进行真实浏览器、真实触屏、200%浏览器缩放、低端手机帧率和跨浏览器检查。环境缺少规定的control-browser能力，未启动替代预览服务器。
