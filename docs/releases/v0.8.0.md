# 余烬农场 · 持续完善清单

当前交付：**v0.8.0「清晰视野」**。实际基线：v0.7.0「营地回响」。更新日期：2026-10-06。

本轮集中完成：世界视野分区、六大玩法统一手册、事件与操作反馈重构。沿用像素场景、20个事件及42条路线、现有在线地址、正式存档与两套独立试玩。更难的统一生存规则继续生效，没有新增难度选择。

## 先这样试玩

1. 进入首页核对“v0.8.0 · 清晰视野”。选择“继续生活”使用正式进度，或选择“试玩营地回响 · 20事件”进入独立试玩。
2. 在世界中移动：上方是生命、体力、饥饿和时间；下方是固定工具栏与一条当前目标。地图有自己的渲染区域，角色与目标坐标随该区域调整。
3. 按N/F或点击“营地手册”。先选农业、生产等系统，再在项目列表中选择作物、供水、生产计划或相关操作；右侧只显示选中的内容。
4. 手机点击一个项目进入详情，通过“返回列表”回到原列表。手册底部保留背包、地图、建造、设置；底部快捷栏可以横向滑动。
5. 进入“营地事件”，切换“全部20条”，选择“封路的粮食车队”。比较投入与结果，接取并选择修车路线，装够材料，标记现场并前往住宅区；现场投入6木材、2零件，等待45游戏分钟，回营完成交接。
6. 进入事件列表底部“营地服务与改装”，体验车队留下的资源交换。完成事件后会自动保留已解决详情，方便查看实际奖励与后续用途。
7. 背包中选木材、干粮或药品，查看右侧用途、来源、当前需求；窄屏显示在物品格上方。世界地图内可查看当前区域缩略图。
8. 触屏选择建造设施后，移动角色确定前方预览位置，用“旋转”“使用”“取消建造”操作。战斗中可以按住“使用”，枪械可点击“装填”；主快捷栏不会因战斗重新排列。

桌面：WASD移动、E交互、左键使用、Tab背包、M地图、C制作、B建造。手册打开时世界暂停；料理操作小游戏按原规则在对应页面进行。等待采用游戏分钟，离线不推进。

## 已完成验证

**176项自动化检查全部通过**：保留此前167项（原界面断言更新为新列表/详情行为），新增9组界面结构与交互检查。原有完整四章主线、42条事件路线、材料不足、背包满、重复操作、失败重试、存档迁移与资源倍率继续通过。

新增检查：带偏移与不同CSS尺寸的鼠标坐标转换；消息合并、过期、战斗延期与数量上限；嵌套控件拆分完整性；六大系统全部项目与原操作入口；20事件逐一选择且只展开一条；服务入口；界面切换不扣资源；旧进度与统一难度；上下分区结构与旧悬浮规则移除。

实际game.js控制器通过DOM替身检查：资源加载、正式/v5/v7存档隔离、生产/水渠/料理、事件装包/旅行/支付/等待/结算/服务、地图筛选、背包详情、独立Canvas矩形、指针坐标、菜单滚动恢复、返回与重开、触屏按住连续使用和重复点击防护。替身不执行CSS布局，不等同于真实浏览器测试。

实际Canvas使用原素材绘制1366×600、1920×912、390×520、844×240、683×236、320×300的独立视口，并检查建造范围、水分信息、目标标记与仓库事件缓存。已人工查看桌面和手机尺寸场景；这些图片只包含世界渲染，不包含HTML界面。当前原生Canvas缺少完整中文字体，不能用它验证中文可读性。

可复现命令：npm test。控制器检查：node scripts/check-ui-controller.mjs（需要当前环境提供的@napi-rs/canvas）。所有测试使用隔离夹具，未读取或改写用户浏览器的实际存档。

## 存档与规则边界

正式保存仍为ember-farm-save-v1；章节试玩仍为ember-farm-demo-v5；事件试玩仍为ember-farm-demo-v7，各自保留备份。界面升级不新增玩法存档层，不扣旧金币、不删建筑、居民、物资或事件能力。

普通资源平均2/3产出、作物周期1.5倍、基础采购价格1.5倍、饥饿与受伤加重等v0.7规则保留；没有难度选择。后续新规则仍应通过真实经济与战斗体验验证，不能把自动化通过等同于好玩程度的证明。
