# 余烬农场 · 持续完善清单

当前交付：**v0.10.0「归于生活」**。基线：v0.9.0「五区新生」。日期：2026-10-06。

本轮定位为正式版产品化更新，**尚未标记 v1.0.0**。HTML/Canvas、像素资源、十张地图、六大玩法、四章主线与同一在线地址保持。统一高难度规则不改，不新增难度选择，不赠送演示资源。

## 已完成

### 玩家入口与界面

- 标题页改为“继续游戏 / 开始新游戏 / 设置 / 制作人员”，以农舍与土地为叙事，显示实际存档的游戏日与所在地。
- 版本仅在标题页、设置、制作人员和加载页显示；HUD与管理面板不再反复展示开发版本标签。
- 删除正式控制器中的三个演示启动函数、独立试玩切换路径与定位快捷动作。旧的各版独立存档留在浏览器原键中，正常操作不读写它们。
- 设置可在开始游戏前使用，声音、字号、场景缩放及地图选项独立保存。游戏内返回标题必须先保存；保存失败时保留当前游戏。
- 主线、地区事务、事件与旧营地总览移除参考链接、开发清单、可玩点统计、内部编号和试玩介绍。功能说明、消耗、时长、暂停原因、风险和恢复办法继续保留。
- 原公开 progress 页面移至本仓库 docs/development，不随游戏站点发布；参考出处继续保存在历史发布记录与数据定义中。游戏内无开发记录入口。
- 地区事务展示设施名称、工作状态、仓库、运输和收支，地图及场景使用地名、地标和目标标记；不再用“体验完八项”表示地区发展。
- 标题页采用分栏与窄屏单栏布局；通知可以换行；设置和档案列表使用一致的按钮与分组。菜单暂停世界，管理面板占用独立滚动区域。
- 移除旧地图上无实际筛选对象的一组按钮，保留作用于真实地区卡片的筛选。
- 调查页只显示已经取得的日志、测绘和水质证据；未获得的证据显示取得方法。

### 连贯成长

- 新玩家起步提示根据实际田地变化，依次给出清地、播种、浇水、等待生长、收获的当前行动，可标记对应地块。
- 前期引导使用正式开局的80金币与有限物资；没有使用演示营地。东侧已有篝火灶的事实反映在提示中。
- 获得首次收获、首次出售、救回阿禾、恢复医院、陈工与动力研究等实际成果后，营地手册出现相应通路机会。
- 地区机会说明修路位置、材料和后续用途；既有存档根据已经完成的成果直接获得引导，不要求重做任务。
- 主目标优先显示，地区机会作为另一项可选事务。主线完成后继续展示长期合同、人物故事、地区建设与经营。
- 事件和主线追踪会清除原地区追踪，避免同时存在两个不同来源的主目标。

### 存档安全

- 正式键仍为 ember-farm-save-v1，备用键仍为 ember-farm-backup-v1；状态结构延续原迁移，不重置金币、地块、角色、任务、建造或物流。
- 主存档缺失或损坏时读取有效备用文件。保存时不再把损坏主文件覆盖到有效备用文件。
- 新游戏必须经过确认；新游戏与导入分别保留一份替换前的恢复检查点，检查点写入失败则中止替换。
- 检查点可以保留尚未自动保存的当前游戏。导出的历史与恢复文件支持重新导入，并选择要恢复的家园，再次确认后替换。
- 历史独立试玩存档不会自动转为正式存档，也不能通过导入覆盖当前家园；原始数据可随历史备份导出。
- 文件导入上限32MB，兼容包含多个历史槽位的备份。读取异常、空间不足与无法保存均显示明确原因和恢复方式。
