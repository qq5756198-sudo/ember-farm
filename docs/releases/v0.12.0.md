# v0.12.0「路与目标」

基线：v0.11.0「边界之外」。2026-10-06。

## 玩家反馈与处理

玩家表示功能太复杂、看不出作用，地图混成操作面板。本轮整理现有功能，不新增资源难度、地图或独立试玩档。

- 世界地图使用十五地区的地形、路线、地名与开放状态。选择地名仅查看用途、开启条件、开路材料和通行限制；删除地图内的地区手册、事件、生产、运输管理入口。
- 未开地区逐项勾选前置条件；入口位于未开放的上游地区时，定位最近可达的入口。选点和标记不消费材料、不移动玩家。
- 本地地图标出人物、设施、入口、仓库和当前目标的名称。小屏地图可滚动，条件区独立滚动。
- J / N / F 及常驻“任务手记”统一进入一个当前目标。主线显示缘由、具体下一步、实际交付与成果；收获阶段逐步提示清理、播种、浇水和收获。
- 为已有功能提供12份家园委托与80份地区设施委托。默认只提示最多两项支线，完整列表按已开放地区选择。委托读取既有真实状态，不重复发奖励，也不要求已使用的设施重做一遍。
- 任务可直接打开所需配方、标记现场、进入相关单页或只显示当前需要建设的设施。干粮和绷带展示材料拥有量、来源、产出、加工时间及领取按钮；重复点击不会创建第二批。
- 地区现场工作默认只有当前设施，常规动作显示成本后直接执行；危险挑战、拆除及关键选择仍预览确认，批量与管理功能保留。
- 引导焦点、地图目标随正式存档保存。旧存档仅添加独立guidance字段，历史独立档不改动，原版地图、人物、物资与统一高难度保持。

## 验证

- `npm test`：348项测试通过，0失败，包括旧内容回归和10项新增导航/存档/任务/安全支付测试。
- `npm run test:ui`：实际game.js控制器与DOM替身通过。新手真实收获→干粮加工→领取→推进主线→开路→保存恢复；所有92份任务卡及下一操作、15地图选点、本地地图、80设施页、旧新事件与管理入口均执行检查。
- 原生Canvas在1366×600、1920×900、390×480、844×240场景尺寸完成绘制。此项只验证Canvas与控制器，不等同网页布局验收。
- 旧存档逐字段比较、错误引导字段拒绝、锁定地图不移动不扣资源、材料不足无扣除、满包领取失败保留成品、重复领取与重复维修、危险动作保留确认均覆盖。

## 待验证与限制

当前环境没有可用的control-browser技能，未启动浏览器预览。真实浏览器1366×768、1920×1080、触屏、200%缩放的CSS遮挡、焦点、滚动和中文字体仍待实机验收。响应式规则已编写并人工审查，不能将其声称为真实浏览器测试通过。

设施委托目前以完成该设施的一次真实工作介绍用途；后续可以按玩家最容易卡住的环节细化为多阶段人物委托。部分复杂的跨区排班与运输仍在独立高级面板保留。

## 建议体验

继续旧档，按M查看地图和未开放地区条件；按J看当前任务，尝试“下一步”按钮；到溪谷分水闸或其他设施按E，体验单页操作和任务用途说明。新档可体验清田→播种→浇水→收获→干粮加工。
