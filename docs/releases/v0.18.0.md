# v0.18.0「每日抉择」

基线：v0.17.0「远方来客」。日期：2026-10-07。按《余烬农场 · 每日抉择事件方案（100 个事件）》实施，方案里的五个待定项都按推荐做：

- 一百个事件，每个三个选项；
- 保留 v0.17 的“夜里的抉择”；
- 06:00 以后卡片不能关；
- 从第 2 天开始，第 2–5 天只出新手事件；
- 冒险选项标出成功率。

保留 HTML/Canvas、像素素材、十五张地图、六大玩法与玩家存档；统一高难度，没有难度选择。没有新增独立管理面板：事件卡是清晨自己弹出的一页，进度挂在任务手记里，“抉择记录”从手记进入。

## 每天清晨一张卡

- **时间**：每天零点定下当天的卡（事件、三个选项、冒险的运气一起定好），06:00 起世界暂停、卡片自己弹出。正在打仗、钓鱼、摆建筑，或者灰隼团、尸潮正在预警或进攻时不弹，“需要处理的事”提醒栏写“今日抉择等你决定”，安全了再弹。
- **不能关**：06:00 以后，卡片右上角的 × 和底栏都隐藏，按 Esc 只提示“先选一个，再开始新的一天”。06:00 前从任务手记里提前打开的可以先关上。
- **三个选项**：每个选项写清花费（带现有库存）、得到什么、后续；冒险的写“几成机会”，下面一排十格的条，绿格是成、红格是落空，并写清落空会怎样。东西或金币不够、条件不满足的选项按钮变灰，下方写原因，点了不扣任何东西。
- **按 1 / 2 / 3 选**，触屏直接点“选这个”；选完是结果页，列出花掉和得到的每一样，按“开始第 N 天”回到场景。
- **一天一次**：同一张卡选过就不能再选，读档、双击都不会再给一次；读档后卡片和运气不变，不能靠读档重抽。
- **没选的卡**：一直没弹出来（比如整天在外面打仗）的卡，到第二天零点记成“错过了”。午夜到清晨之间想睡觉时，先把当天的卡定了再睡，不会一觉睡过去。
- **奖励倍率**：第 3–5 段 ×1.5，第 6 段起 ×2，物资、金币和花费一起放大，卡上标“奖励 ×1.5 / ×2”。连贯事件整条线用开头那天的倍率，借多少、还多少对得上。
- **运气**：连着两次冒险落空，下一张卡上冒险的成功率多两成，卡上写“运气在你这边”。

## 一百个事件

| 类别 | 数量 | 例子 |
|---|---|---|
| 连贯事件 | 9 条 · 36 个 | 迷路的信鸽、地窖里的敲击声、破伞剧团、井水变色、野狗群、电台里的女孩、黑市的借据、种子库的钥匙、抛锚的卡车 |
| 农事与天气 | 12 | 早霜、虫害苗头、怪南瓜、田鼠打洞 |
| 拾荒与远征 | 10 | 旧地图、万里晴空、废车堆、超市冷库 |
| 营地生活 | 12 | 洗澡日、偷懒的人、守夜轮班、婚礼 |
| 交易与访客 | 10 | 路过的小队、押运的邀请、集市拍卖会 |
| 危机与威胁 | 10 | 围栏被挖了洞、感染者靠近、枪管生锈、疫病传言、塌方 |
| 奇遇 | 10 | 彩虹、迷路的鹿、一桶好酒、双胞胎小猫 |

- **新手事件**：13 个，只给好处或很小的取舍，第 2–5 天只从这些里抽。
- **抽卡规则**：
  - 到期的连贯事件优先；
  - 没见过的事件权重 ×3；
  - 和昨天同类的权重降低；
  - 危机事件最近五天出过一次，就先不出（救急类除外）；
  - 独立事件 30 天内不重复；
  - 同时最多进行 3 条连贯事件。
  - 很多事件有出现条件（第几段以后、有没有麦穗、鸡舍、援建队员、电台），条件不满足就不出。
- **连贯事件**：每一步的选择会记下来，影响后面：
  - 第一步“记下数字”，后面才能说出暗号；
  - 剧团的门票分了一半，团长就不肯留下；
  - 撬锁失手，种子库只剩一半种子；
  - 下井摸清了管子的走向，后面不用再专门跑一趟。
  - 有的步骤要你亲自去某片废墟的标记点（插紫旗的木桩）看一眼，去过的第二天早上有下文。任务手记写明去哪，可以一键标出位置。
- **结局与长期加成**：九条线走到结局时可以选长期加成，共 17 种，例如种子网、地下避难所、蓄水池、守夜犬、前哨运输车、黑市渠道、石子路。已经有的加成不能再买一次。

## 效果

选项的效果都由一小套固定动作拼成，卡上的文字和实际结算用同一组数字。

| 效果 | 说明 |

| 即时 | 物资、金币、声望、士气、疲劳、生命、体力、研究点、经验、人物信任、麦穗默契、彭姐关系 |
| 延后 | 几天后 08:00 送到的回礼（入仓）、要交的债、当晚可能丢的东西（有哨兵、守夜犬、看田犬、猫或守夜轮班就不丢）、连续几天少一份收成 |
| 限时增益 | 作物生长、加工速度、受到的伤害、补给箱多拿、出货价、出远门不花时间、士气每天上涨、清晨自动浇田、电台效果翻倍、防守力。顶栏“✦ N”标签列出生效中的增益，点开看抉择记录 |
| 场景里 | 今天的补给点：插金色绸带的木箱，放在某片废墟的空地上，按 E 打开一次，过了今天就没了 |

|  | 招来的感染者：打完领赏，只领一次 |

| 买卖 | 唐九商队打折或多带一件枪械配件、卖掉最多的东西、用背包里的货抵账 |

## 界面

- **事件卡**：
  - 类别像素小图、类别与连贯事件的步数标签、“奖励 ×N”标签；
  - 上一步你选了什么；
  - 三张选项卡，宽屏三列，900 像素以下单列；
  - 底部写相关库存和金币。
- **结果页**：赢了标题变绿、落空变红，逐条列出变化与后续。
- **任务手记里的“今日抉择”条**：今天选了什么（没选的有“现在决定”按钮）、进行中的连贯事件走到第几步、标记点在哪（“标出位置”按钮）、生效中的增益，以及“抉择记录 · N 张”。
- **抉择记录**：最近 30 天的选择、九条连贯事件的状态与结局、已得的长期加成、生效中的增益；总共做了几次抉择、冒险几次成几次。
- **色弱友好配色**下，成功率条改为蓝 / 橙，风险文字改为蓝色。
- 触屏上不显示“按 1 / 2 / 3 选择”。

## 和方案不一样的地方

- 方案里的“新居民”都改为加入援建队（上限 3 人，满了留下谢礼），不另开居民名额。
- C3-3“给他们收拾一间空屋”改为花木材 6，不要求床位。
- C4 结局“改成蓄水池”：每天清晨自动浇 6 块田。
- C8-2 查资料用联盟终端，不找苏砚。
- C5-2 第二个选项改为“扔石头吓走”（体力 −10）。
- C7 卡面不写死金额，选项里按倍率写清借多少、还多少。
- V09 第三个选项“拿最多的东西去卖”，V10 第二个选项“请她指点一二”（研究点 +1、许医生信任 +1）。
- N10 给种子，不给产量加成；L07 是修理、带徒、干活三选一；J03、J09 给研究点，不给照片；D03 改为枪管生锈；V06、V08 简化。
- C2 的避难所只挡灰隼团的流弹。

## 存档

- 新增 `daily` 字段（schema 1）：
  - 当天的卡与三个运气值；
  - 最近 60 条记录；
  - 进行中与已结束的连贯事件（含每一步的选择记号、标记点、开头那天的倍率）；
  - 每个事件上次出现的日子、限时增益、长期加成、延后送达；
  - 今天的补给点、埋伏、招来的感染者与赏金、清掉的废墟、预警加成记录、唯一奖励记录、统计。
- 没有新增存档键，正式键、备用键、各检查点与历史键全部保留。
- v0.17 及更早的旧档直接读取，补上空的抉择字段，第二天清晨开始出卡。
- 损坏或前后矛盾的字段会被拒绝，读取回退到有效备份，例如：
  - 事件编号不存在；
  - 连贯事件同时在进行又已结束；
  - 补给点在不存在的地方；
  - 同一条奖励记录出现两次；
  - 用 `constructor` 这类名字伪造的编号。

## 已知限制

- 第一天没有卡；新手期（第 2–5 天）只出 13 个新手事件，可能会重复见到同类。
- 卡片在打仗、钓鱼、摆建筑时会一直等着；一整天都在打仗就会错过那张卡。
- 补给点只放在居民区、旧医院、仓库、集市四个固定位置之一。
- 冒险的运气在零点就定了，换选项不换运气（三个选项各有一个运气值）。
- 援建队满员后，后来的人只留谢礼，没有替换队员的选项。
