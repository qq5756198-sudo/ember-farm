# v0.16.0「前哨四季」

基线：v0.15.0「寒潮之后」。日期：2026-10-07。按扩展设计方案中标为 v0.16 的 17 项（6 项玩法、6 位人物、5 项界面）实施。主线故事在 v0.15.0 已完结，这一轮补的是前哨日常：节庆、吃饭、聊天、带徒弟、来来往往的人。

保留 HTML/Canvas、像素素材、十五张地图、六大玩法与玩家存档；统一高难度，没有难度选择。没有新增独立管理面板：节庆和食堂在场景里的前哨广场，日历点顶栏日期打开，人物关系挂在营地手册居民页和任务手记下。

第三段之后，节庆、借宿、营火夜谈与新人物陆续开放；已经走到后面段落的旧档读入后直接开放。

## 六项经营玩法

### 前哨日历与节庆

- **时间**：每 7 天一次（第 7、14、21… 天），当天 16:00–22:00 在前哨广场（农场东边的长桌）按 E 主持。
- **四种节庆轮换**：

  | 节庆 | 要交的东西 | 奖励 | 广场装饰 | 加分项（第一颗星） |
  |---|---|---|---|---|
  | 换种集 | 仓库里最多的 3 种种子，各 2 份 | 换回 3 种少见种子各 3 份（每颗星 +1）、黑麦种子 2 份 | 换种集彩旗 | 农场有摊位 |
  | 灯火夜 | 木材 4、布料 2 | 居民士气 +6（每颗星再 +2） | 灯笼串 | 至少两盏暖光灯 |
  | 丰收评比 | 仓库里最多的 3 种作物，各 2 份 | 60 金币（每颗星 +20；本周收获展得奖再 +40） | 丰收拱门 | 本周收获展交过展品 |
  | 守夜纪念日 | 干粮 6 | 所有认识的人信任 +1 | 纪念石 | 至少一座瞭望塔 |

- **另外两颗星**：生活水准到“吃得好”；阿砾画了两幅以上壁画，或老琴今晚唱过。
- **其他规则**：
  - 每次节庆另有声望 +3（守夜纪念日 +5）。
  - 装饰两件以上，居民士气每天 +1；四件 +2。
  - 节前一天 08:00 会提醒。错过只记一笔，不罚。
  - 节庆当天不排尸潮，顺延一天。
  - 一周内办过节庆，算生活水准的“有盼头”。

### 布局相邻加成

| 关系 | 加成 |
|---|---|
| 篝火灶靠近仓库箱 | 加工 +20% |
| 制作台靠近仓库箱 | 加工 +15% |
| 罐装机靠近篝火灶 | 加工 +20% |
| 武器工作台靠近制作台 | 加工 +15% |
| 鸡舍旁有 3 块以上农田 | 附近作物 +10% |
| 雨水桶被 4 块以上农田围住 | 附近作物 +8% |
| 瞭望塔紧挨围栏或大门 | 射速 +25% |
| 床边有暖光灯 | 休息的居民每小时多恢复 2 疲劳 |
| 餐桌靠近篝火灶 | 食堂评分 +10%，晚饭士气 +1 |
| 摊位靠近营门或餐桌 | 摊位售价 +10% |

- 建造预览直接显示加成或提示。
- 建造模式下，已经生效的配对之间画金色虚线。
- 加工站菜单里也会写出相邻加成。

### 前哨食堂营业夜

- **开张条件**：何大勺入伙后，每 7 天里的第 2、5 天，19:00–21:00 在广场按 E 开张，21:30 打烊。
- **客人**：一晚四位，每 20 分钟来一位，各自说想吃什么口味（顶饱、热乎、鲜味、甜口、讲究）。
- **上菜**：用做好的菜。对口的菜收菜价约 1.8 倍，不对口的约 1.2 倍。
- **耐心**：客人等 50 分钟（约半分钟实时）就走。
- **口碑**：打烊时按对口、不对口、走掉的人数结算。
  - 口碑 ≥50：集市收购食物贵一成；
  - 口碑 ≥70：唐九早一天来。
- 营业中去睡觉会先打烊。

### 营火夜谈

- **时间与地点**：晚饭后 19:00–23:00，在援建营地按 E（营火旁会提示“营火 · 夜谈”），一晚一次。
- **在座的人**：信任最低的三位居民、援建队员或入伙的人物。
- **话题**：
  - 说说以前：在座信任 +1；
  - 聊聊明天：居民士气 +4；
  - 今天的事：农业与战斗经验各 +4。
- **安慰**：有人心情不好时，可以只陪那一个人坐，士气 +12、信任 +2。
- 每第三次夜谈会听到点消息：歌谱的下落、尸潮日期，或一把种子。

### 学徒与手艺传承

- 阿禾、陈工、许医生各能带一名援建队员，三天出师；带徒期间加工慢一成，师父更累。
- **出师后的第二份工作**：
  - 浇水：每天 07:00 浇最多 6 块田；
  - 维修：10:00、15:00 修最破的设施 15 耐久；
  - 包扎：18:00 用 1 条绷带治好营地病号；你在农场受伤时顺手包扎 15 生命。

### 过路人借宿

- 每隔三四天的 20:00，有人在营门借宿，23:00 前答复。
- 留宿要 1 张空床或一间布置好的房间，再加 1 份口粮。
- **第二天一早留下谢礼**：种子、消息（尸潮日期、商队日期）、零件与布料，或一份家乡菜。
- 约四分之一的人想留下，会在当天上午走入营审查。

## 六位人物

| 人物 | 出场 | 故事与能力 |
|---|---|---|
| 何大勺 | 集市，第三段后 | 菜谱本丢了，口述三道菜：行军炖菜 → 萝卜糕 → 鱼片粥。按顺序做出来端给他尝。三道都对上后搬到前哨，开食堂营业夜，再教豆渣饼、炊事班大饼。五道新菜都能当晚饭 |
| 秦奶奶 | 第一位借宿的人 | 三个心愿：再看一次海（去沉湾船坞，或给她看拍到池塘水面的照片）、吃一口萝卜糕、听一首老歌（电台《点歌》《老歌》或老琴）。都了了就坐渡船去找女儿，留下老照片：居民士气每天 +1。住满 7 天心愿没了完，她也会先走 |
| 阿豆 | 第一次节庆后，第四段起 | 仓库连着两晚少干粮，第三晚 22 点后在仓库箱边能碰到他。抓住他问清楚，或假装没看见（第二天有字条）。他妹妹病了，送一份绷带、草药茶或药包后，他当前哨跑腿：区域送货快四分之一，夜里守仓库，小偷偷不走东西 |
| 阿砾 | 第一次节庆后 | 在南边围栏上乱画。骂走他，下次节庆后他还会溜回来；或者让他把前哨的大事画下来：每完成一段故事，围栏上多一幅像素壁画（每天画一幅）。三幅以上居民士气每天 +1，两幅以上算节庆的一颗星 |
| 老琴 | 节庆之夜在广场 | 点一首歌：居民士气 +3、算节庆的一颗星。之后托你找回散落在集市、住宅区、旧医院、工业仓库的四张歌谱。歌谱进电台节目单：《老歌》每张歌谱让居民士气 +2 |
| 江伯 | 林边池塘 | 一串委托：两条银鳞鱼（鱼竿升级，咬钩快 0.4 秒）→ 一条蓝背鱼（再快 0.4 秒，弹药 6）→ 钓到变异鱼（接委托后在农场池塘有机会钓到；转交许医生，研究点 +1）→ 放流净化鱼苗（药草 2、银鳞鱼 1，咬钩再快 0.3 秒） |

另外：

- 每个人有信任（0–10，五颗心）、两样喜欢的东西和生日（每 28 天一轮）。
- 每人每天可以送一样喜欢的东西，信任 +1，生日当天翻倍。
- 居民信任满三颗心，士气每天 +1。
- 援建队员满三颗心，缺一顿饭也不会赌气变慢。

## 五项界面升级

- **节庆日历**：点顶栏的日期打开，显示未来两周，例如：
  - 节庆、食堂营业日；
  - 唐九的商队、尸潮、灰隼团、寒潮；
  - 营门来人、生日。
- **人物关系页**：每个认识的人的信任心形、喜好、生日和下一步故事条件；送礼按钮；带徒在页底。
- **同处多对象选择**：两个不会走动的对象几乎一样近时，E 先弹出小选择条，按数字键或点击选择，提示条会写“选择：A / B”。以下情况不弹选择，照旧直接交互：
  - 站在遗落的背包、农田、联盟终端上；
  - 身边是走动的人；
  - 正在钓鱼。
- **物品来源与用途链接**：背包物品详情里多了“从哪来 / 能做什么”。
  - 加工配方：点一下打开对应设施，没有就打开建造并定位到它；随手制作的配方打开制作菜单。
  - 商人有卖的：在集市立路标。
  - 鱼与种子：标出池塘或农田。
- **渐进解锁与“新”标记**：
  - 功能第一次开放时，入口按钮带红色“新”，任务手记按钮右上角有个“新”点。
  - 第一次打开时，页面顶部有一张说明卡，十秒后变淡，以后不再出现。
  - 覆盖：节庆日历、人物关系、前哨广场、法令簿、电台、档案馆、成就册、寒潮页。

## 已知限制

- 灰隼团只向玩家开枪，不攻击居民、队员和建筑；不在农场时用公式结算。
- 援建队员、客人、借宿者、新人物都是“重新上色的人物精灵 + 头饰”，没有独立动画。
- 出货箱价格不随日期浮动。
- 方案里秦奶奶“船坞航线提前开放一次”没有做：直接开放船坞会绕过原有的修路与建造条件。改成老照片的长期士气加成，再加声望 +3。
- 节庆当天顺延尸潮只处理排在节庆日的那一次，已经过期的尸潮不会再顺延。
