# 余烬农场 · 持续完善清单

当前版本：**v0.33.0「盼头」**。基线：v0.32.0「手感」。日期：2026-10-17。

依据的方案：《余烬农场：爽点与耐玩体检方案》。玩家说“按体验的不好玩地方全面修改”，五件要拍板的事按方案推荐的做：顺序手感 → 盼头 → 成长 → 长夜；钱花在已有的地方（墙升二级、商队和旧站商街的稀罕货、农舍仓库鸡舍扩建，不加营地开销、不给战力）；长夜夜相轮换、输了也留东西，难度线不动；技能上限放到 10 级，后 5 级只给方便和花样；种地按住连做加汇总提示，自动化的数不动。第一版「手感」在 v0.32.0；这一版做第二版「盼头」：方案第 3、2、9 条；下一版是 v0.34.0「成长」（第 4、6 条和第二年清单）。

## 和方案不一样

1. 稀罕货里没有图纸（图纸多是武器防具，给战力）；稀有种子是金穗种子包，旧物线索是货郎的账本。
2. 唐九的商队那一周带两样稀罕货（方案写一样），还两倍价收一样菜。
3. 下午的“过路人只待到傍晚”做成了货郎；有小故事的过路人在“这周的事”里待四天；下午的事多了鱼汛、被困的人、翻倒的物资车。
4. 长夜那天也有下午的事，只放农场里的三样。
5. 二级电网是夜里田里的菜快两成五、多四盏路灯（只是画面），不是“路灯照得更远”。
6. 货郎的添头、收购先挑你手上有的、鱼汛只放有好鱼的水（方案没写）。
7. 档案馆的旧物、残页、检修电梯是大事卡片（方案没写）。
8. 鸽子来信（方案没写）。
9. 第二年换一批清单、打法挑战放在下一版「成长」（排期本来如此）。
10. 鼎丰的价钱没动：全套 5.6 万还是勤快玩家 15.7 天的收成，第 29–30 天攒够。
