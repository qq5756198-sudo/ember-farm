# 余烬农场 · 持续完善清单

当前版本：**v0.39.0「一物一用」**。基线：v0.38.0「修缮」。日期：2026-10-21。

依据的方案：《余烬农场：一物一用简化方案》。玩家说“游戏总感觉就是好多东西很复杂，但是我又不知道有什么用……每一个物体就对应一个功能就好了，别插那么多复杂其他功能出来，想想办法做个方案再修改”。方案分三版：v0.39「一物一用」（挪地方、补说明、该自己干的自己干）→ v0.40「删繁」（去掉和合并，旧档转换）→ v0.41「上手」（用得上的时候才出现、第一次见到的小卡、开局引导）。要拍板的五件按方案推荐的做：妙手并进探索、天赋自动、喜好明着写、菜地只留种浇收和一种肥、分三版。这一版做第一版。

## 已完成

- **一样东西一件事**：不再弹“选一个”，按交互是离你最近的那一样，头上、底栏都写“名字 · 做什么”，触屏交互键写着做什么；联盟终端只读来信；援建营地开派活；居民开他在“人”那一页；地区入口修通了直接进、没修通开“修通路”的卡；地区出口直接回；麦穗摸一下；设施开它的卡（坏了一个“修好它”），有配方的只列自己的；农舍只休息。被抓着、撬锁、收线、蹲在人背后时交互照原来的意思。
- **自己干的**：加工好的东西自己进仓库（主线照样算）；农场上掉的东西进仓库，旧档地上堆着的读进来就收进去。
- **菜单十项**：“☰ 菜单”大屏也有，十项各一句话（任务手记、背包、制作、建造、地图、人、成就册、消息、技能、设置），下面拍照、脱困；消息一页看发生过的事；十几个页最上面一张卡写这一页做什么。
- **说明卡**：建造页分种地、吃住、防守、摆件四组，每样一句做什么、一句好处，没研究出来的收成一行；背包里一样东西的卡（好处、身上和仓库各几份、从哪来、能做什么）；顶栏十个数点开是卡；提醒最多两条。
- **各页只留一件事**：任务手记只留任务；制作只列随手做的 8 样（原来 215 个按钮）；出货箱、菜地告示牌、档案馆、援建营地、地区的页拿掉挂上去的别的功能；收获展挪到前哨广场、联盟援建清单挪到重建站、伙伴与相册挪到成就册、营火夜谈和麦穗挪到人、房间与家具挪到建造页。
- **场景里的字**：只有面前那一样头上一行，别的东西的名字和状态字不画（出口、感染者、你自己、飘字照画）。
- **拆东西**：建造页“拆掉一样设施”→ 点设施 → 卡上“拆掉它（退一半材料）”。
- **顺手修好的**：清晨抉择清掉了的废墟尸堆里不再爬起人；手机竖着拿右上角“☰ 菜单”不再被挤出屏幕（饥饿条也不再被切），翻滚 / 使用 / 交互那一排不再出屏幕（这两处 v0.38.0 就有）；两个时好时坏的老测试定住了。
- 新文件：`dist/simple.js`（引擎最上面一层）、`dist/simple-data.js`（每样东西做什么、说明卡的字）、`dist/simple-ui.js`（卡、菜单十项、顶栏的卡、来信、消息、修通路几页、拿掉挂上去的功能）、`dist/simple-renderer.js`（场景里的字）、`dist/simple.css`；`tests/simple.test.mjs`。

## 和以前不一样的

1. 按交互不再弹“选一个”：几样东西挨着时是离你最近的那一样（它头上写着字）。
2. 联盟终端只开来信（原来开整本任务手记）；居民开“人”那一页（原来开安排干活那一页）；地区入口修通了直接进去、出口直接回去（原来开地区那一页）；麦穗按交互是摸摸它。
3. 加工好的东西自己进仓库，不用再点“领取”；农场上掉的东西直接进仓库。
4. 农舍只有睡觉和歇到天黑；房间与家具在建造页，存档在设置。
5. 制作页只有随手做的；设施的配方到那台设施跟前按交互。
6. 任务手记只留任务；别的玩法的条子回到各自的东西上。
7. 场景里只有面前那一样写字。
8. 顶栏的数点一下是一张卡（日子那张卡上有“看日历”）；提醒一次最多两条。
9. 手机竖着拿时顶栏左边只留 ✦（“余烬农场”四个字收起来），时间的字小一号。

## 待完善 / 下一轮优先级

1. v0.40「删繁」：水网、地力和别的农活（只留种、浇、收和一种肥）、心情改成士气、政令、动静、电台节目和指令、手气签、来信、藏东西、地区仓库并成一个、天赋自动、妙手并进探索、设施 36 → 26；拆掉的全退料，旧档照读、升级前留一份。

3. 已知限制继承：
   - 出货箱、菜地告示牌这几页原来那段说明还在卡下面，和卡说的有一点重；

   - 食堂开张还在前哨广场按交互（广场那一行写着“开张食堂”）；电台节目、机床加急、出货挂牌、地力、改良留到下一版并掉；

   - 浸泡、重光台、守夜台的机器人照旧有它们的限制（不照清单种地、不换武器、不挪布置……）；
   - 横着拿手机时，蹲行、投石、推开、建造排成一列要上下滑。
4. 真机与其他浏览器验收后，再考虑 v1.0.0。
