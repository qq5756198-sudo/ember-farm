先让新增内容接回现有家园

核对了当前事件、地区、成长与渲染代码以及 v0.10.0 发布记录。现有内容已包含“营地回响”20事件、十张地图、40个新区点位，以及育种、轮作、伙伴犬、照片、生态修复、房间、政策、三站远征和跨区货运。以下不把它们重新命名后当作新增功能。

本轮目标是延伸六条主线，而不是再增加六条互不相干的资源条。20个事件是这些玩法的具体经历；20项玩法延伸是可持续使用的机制；20项画面升级负责把结果呈现在世界中。它们彼此关联，但不重复计算为60种独立系统。

种植与保种 → 制作口粮、布料与防护 → 居民与伙伴协作 → 勘察和解锁新地 → 带回工艺、路线及盟友 → 改善家园和防线 → 接受下一次地区行动

20部小说，20处有取舍的玩法延伸

选书兼顾中文末日网文与国际畅销、经典灾后小说；这不是“当月热度前20名”的排行。《发条女孩》《播种者寓言》侧重生态灾变与社会崩坏，不都属于丧尸小说。出处核对的是作品、作者与相关主题，没有声称逐章通读全部作品。

下表把“原作主题”与“本游戏原创设计”分开。只借鉴叙事动力与生存问题，不照搬原作人物、台词、专有怪物、剧情或封面。出处留在开发文档，游戏内采用本世界的人物与表达。

沉湾船坞外湾航线；原四章主线完成，M2固定渡运建成，M4测向台恢复。无须做完全部事件或全部地图点位。零件6、电路2、布料6用于导航、固定绳与防潮装备；不要求岛上材料解锁岛本身。保存什么、先帮助谁、如何把知识带回家，形成主线后的可持续目标。
8个可玩地点真正能做的事
1. 礁岸登陆点核对测向信息，设置可清楚辨认的离岛路线。
2. 防潮档案库优先保存农业、工程或生活资料，其他类别以后继续恢复。
3. 旧事故记录室把新增上游记录与已知污染证据连接，不推翻旧主线。
4. 公共种源库为已掌握品种留一份备种，种子用尽时有付出成本的恢复路径。
5. 工艺试验庭把残图做成原型并实际改善设施，开新配方而非纯数值升级。
6. 生活史展厅展出玩家真实照片与居民物件，来访者带来后续个人故事。
7. 避风撤离港发起最后一班渡船分段行动，决定人、货与中转补给的比例。
8. 复兴议事厅承接家园约定和家庭安置，生成有建设结果的长期项目。

独特收益：替代工艺、种源备份服务、公共档案与家庭安置项目；原家园继续发展。

再次前往：轮换档案主题与自选联合行动，采用不同种植、供餐、运输方案；不重置地图和存档。

上述材料数量是首轮平衡起点，需用当前高难度新档与中后期旧档实测校准。入口建设使用已有地图可获得的材料；任何新地图都不能要求先取得本图独有材料才能进入。已有存档自动识别旧里程碑，不要求重新救人、重建或重做主线。

难度、节奏与信息量

问题设计约束
难度来自什么保留当前资源、价格、成长与战斗规则；新增难度来自载重、路线、班次、设施槽位和用途冲突。不继续统一削减所有掉落，也不把敌人全部加血。
避免资源膨胀常规材料沿用木材、废金属、布料、零件、电路与原有作物；初期新增树脂、食盐、滤材三种材料，以及黑麦种子和黑麦作物。残图与方位记录存入调查页，不占普通背包。
新奖励必须有去处树脂→防水和滤材；食盐→便携腌菜口粮；滤材→地下通路维护；黑麦→寒区餐食和供种合同；所有配方展示产出用途。
不增加日常惩罚旧食物不突然新增腐败倒计时，旧作物不因更新被毁；不增加登录奖励、离线事故或现实时间限时活动。
降低多线打扰同时最多2件事件，其中最多1件有时间压力；首次里程碑剧情排队，待玩家查看再接受。主界面仍只有1个当前目标与最多2个可选提示。
战后节奏尸潮或地区行动后至少留1个游戏日的休整窗口，不叠加寒潮和强制救援。轻量生活事件可出现，允许略过。
有意义的选择选择必须至少改变路线、消耗结构、岗位安排、可用服务或场景状态之一。不能只有不同文案和同一奖励。
失败可复盘进入危险段前说明消耗与可能损失；分段保存，保留关键证据和已完成建设，提供明确返回点。
背包与重复操作奖励满包转入有标记的现场待领取箱；重复点击不重复扣款或领奖；中途取消显示可退与已耗内容。
玩家文案提示写“缺少3份布料，可在织布机加工”，不写“未满足模块条件”。研发编号、出处、数量清单与测试状态始终不进玩家界面。

短期目标是完成一次观察、加工、交涉或局部通行；中期目标是使一张地图的一项服务运转；长期目标是完成自己选择的家园约定和跨区安置。事件先给一个可马上开始的行动，再露出后续用途。

完整示例：种豆与棉花 → 准备工作餐、布料 → 阿禾留守农田，玩家带犬进入林场 → 选择保留采脂树 → 树脂和布料制作滤材 → 打通地下医疗路线 → 柏岚在康复期绘图 → 新路线减少下一次远征消耗 → 用节省的物资与热交换工艺完善白霜驿舍。每一步都使用上一环的产出，并带来新的可见能力。

分批实施与验收清单

虽然方案覆盖整个增量包，实施时按相互依赖的系统分批推进，每批保持旧档可玩。当前 v0.10.0 的真实浏览器、触屏与200%缩放验收仍在待验证清单中，应先解决遮挡与输入问题，再叠加场景内容。

批次集中完成的系统事件与地图阶段产物
第一批：熟悉的家园出现新机会互助与消息；可持续林业与危险植被；旧地图和角色表现。M1；E02、E04、E09、E11、E12、E15。首批6个事件可完成，林场可经营，旧地区有事件后果。
第二批：生活与通路连起来人货渡运与邮路；地下通风与试制；居民康复与文化生活。M2、M3；E05、E06、E07、E08、E10、E14、E16、E19。累计14个事件可完成；三张新图可并行经营，地下与水上通路真正运转。
第三批：远方与长期家园寒区作业与测向；污染溯源；分段疏散与长期安置。M4、M5；E01、E03、E13、E17、E18、E20。20个事件全部可达，15张地图形成完整成长关系，五张新图各8点，20项画面升级完成。

验收项通过条件
事件覆盖20个首次流程均可到达；8个轮换事件的变体有实际差异；所有选择分支都有资源或世界状态效果。
地图可达五张图各8点均有真实操作；入口依赖无循环；不靠随机道具、必带伙伴犬或稀有掉落通关。
经济联动用正常有限物资走完一条从种植到新地图服务的完整链条；统计材料收入、消耗与重复劳动，不用测试奖励充当平衡依据。
旧存档保护追加新事件与地图状态；保留旧正式键、备份、已收复状态、照片、设施、库存、队列与货运。旧内容不重复领奖，不被新迁移覆盖。
异常恢复材料不足、背包满、重复点击、取消、中途退出、货运在途、居民被调岗、失败重试和保存恢复均有明确结果。
画面真实一致建筑外观、灯光、人员动作、污染与林地恢复从真实状态驱动；不以纯装饰冒充可用功能。
桌面与触控在真实浏览器检查1366×768、1920×1080、手机横竖屏及200%缩放；任务/建造/战斗提示不遮住角色和退出按钮。
运行性能先记录旧版同设备基线，比较光照、粒子、动画与长存档表现；低显示特效不改变命中、危险提示或资源结算。
真人体验观察新玩家能否说清下一步与奖励用途，老玩家是否愿意重返旧地；如果只剩重复交货，应调整行动内容后再发布。

存档实现建议：新地图建设、采伐周期、事件选择、协议期限、分段行动与待领取箱分别保存；操作扣费和完成标记同事务提交。所有时间基于游戏时钟，菜单暂停、离线不推进。这些开发细节只留在本文件与仓库开发记录。
