# v0.11.0 visual implementation audit

Assets and renderer are code-native Canvas additions. Existing source PNG assets are preserved. No external requests occur during asset generation. Five new scenes are deterministic 1536×1024 canvases; all 40 interaction anchors and the western entrance stay outside exported building colliders.

## Integration

- `dist/beyond-art.js`: `createBeyondAssets()` plus `BEYOND_GEOMETRY`, `BEYOND_ANCHORS`, `BEYOND_THEMES`.
- Use `dist/beyond-renderer.js` as the final `Renderer`, extending the existing district → clarity → echoes → rebuild → frontier chain.
- Existing `dist/renderer.js` has one bounded extension: use `drawWeather(engine)` when provided; retain original rain otherwise.
- Renderer tolerates missing optional beyond state. New objects: `beyondPoint`, `beyondGate`, `beyondStore`, `beyondExit`, `beyondEvent`.
- Optional `settings.visualEffects`: `full`, `reduced`, `off`; these affect decorative atmospheric particles and soft light, not gameplay or enemy cues.
- No interface lists of implementation status, references, point numbers, or test shortcuts were added.

## Verification

`node scripts/check-beyond-art.mjs` passed: **151 native Canvas frames**, 15 regions, all 40 point anchors outside large blocking silhouettes, render sizes 1366×768 / 1920×1080 / 390×844, clear/rain/night/reduced/off variants, all 20 event sets, seven tool/weapon actions, all crop stages, five enemy tells and map previews.

This test is not a real browser, device touch, 200% browser zoom, or performance benchmark. Native screenshots are kept as development outputs under the scratch `beyond-art-check` directory, not exposed in the player game.

## Final engine-contract alignment

The renderer now uses final saved-state shapes: forest regeneration day numbers; local lodge/inn module identifiers; boat `passenger/cargo/roof` modules; mail sent/receipt arrays; three independent 0–3 vision levels; `benefits.cleanRiver`; actual family count; and dog `follow/guard/wait/home` commands. Forest cuts regrow on their saved days. Lodge/inn changes appear at the actual buildings. Three-stage home vision installations, mail receipts, hedge service and family groups visibly reflect saved progress. A `beyondFamily` object renders the actual number of arrived households (up to four visible groups).

The shipyard blocking basin at `(820,350,155,165)` is visible water before `shipyard_drain.pump`, then becomes a drained grid surface after that exact flag. Observation counts cannot light the safety lamp: it requires `shelter_signals.repair`. Reflective buoys emit no glow; powered harbor lamps require the lamp choice and nonzero energy. Home-mode dog is not rendered on remote maps; remote new-map dog has a visual fallback if its engine object is absent.

The smoke script now imports the actual beyond engine, assigns each region for correct map previews, and passes **156 frames** plus assertions for basin changes, repaired-vs-observed safety signals, reflector-vs-powered lamps, and empty-battery darkness. Family, mail, forest-date, boat, room-module and all three vision stages are also rendered.
