# 余烬农场 v0.6.0 · 供给与远行

沿用同一 HTML/Canvas 项目、像素素材、在线地址和保存位置。本轮完善目标备料、有限库存补货与前哨长期合作三项相连系统。

- **目标备料**：主线自动拆成当前建设步骤，也可钉住工程、人物愿望、合同或地区升级；显示缺口、获取方式、在制数量和前哨随身施工材料。递归配方清单抵扣已有材料并复用批次余量。
- **供给计划**：集市第一阶段＋制作台解锁。九种配方，最多三条同时开启，仓库目标1–30份；只消耗仓库普通/耐旱原料，支持保留底线，自动入仓，暂停及实际材料退款。手动成品也可直接入仓解决背包满的问题。
- **地区合作**：三处前哨分别在2、5、9份合同后可投资升级。两种支援方向影响以后每份合同的实际回程物资，三级分别为1、2、3倍；前哨场景同步显示设施规模。

同时修复读档刷新前哨治疗/送粮次数、居民特长忽略岗位、扩建位置被占用少发农田、失守战报漏记最后受击的问题。新功能不会自动开启或消耗旧存档材料。

持续维护的全系统清单、已完成/待完善/待验证、借鉴出处、试玩路线：[docs/ITERATION-LEDGER.md](docs/ITERATION-LEDGER.md)。同一内容随站点发布为 [progress.html](dist/progress.html)，可从游戏当前目标和欢迎页打开。

本轮验证：116项测试通过，完整四章运行实际v0.6引擎；实际控制器的DOM替身检查新增按钮与存档分离；原生Canvas检查1366×768、1920×1080、390×844及三级前哨场景。真实浏览器CSS、触屏、200%缩放和长期平衡仍待验证，详见清单。

正式存档继续使用 `ember-farm-save-v1`；上一轮独立试玩继续使用 `ember-farm-demo-v5`，本轮不更换保存键。新增状态在 `supply` / `supplyVersion: 6` 下，旧版各层版本标识不覆盖。

## v0.5 六大玩法与四章重建

本次将原有系统连接成农业供给、生产工程、远征收复、居民生活、防御战斗、调查复兴六条成长路线。按N/F打开统一入口，按J查看当前目标。界面显示所缺条件、地点、奖励用途与完成后的世界变化；具体旧操作嵌入对应路线，相关按钮可直接定位操作面板。

四章共16个可完成目标：第一章收成、料理、救援与公共餐桌；第二章医疗生产、医院前哨与通道防守；第三章水塔、动力、物流前哨与运输网络；第四章设施调查、封闭检修间、通信核心与广播防守。章节奖励提供下一步所需种子、蓝图或关键电路；重要设备首次拾取必得并受保护。

## 首版功能

- 农场、幸存者集市、居民区、旧医院、工业仓库；每个探索区有固定独特奖励、支路和撤退点。
- 8 种作物，四阶段成长、每日浇水、雨水桶自动浇灌、食用、出售、加工、育种。
- 两名商人、逐日补货、需求加价、可调整数量的交易、交易后余额预览。
- 10 类建造选项，放置预览、旋转、碰撞检查、耐久、维修、回收；大门允许角色通行。
- 近战、手枪、霰弹枪、步枪；装填、真实弹药扣除、枪声引敌、受击反馈。
- 4 种普通感染者、两阶段仓库精英、有限数量的首次尸潮和 90 秒预警。
- 6 个主线目标、4 个幸存者委托、4 类成长技能。
- 自动保存、手动保存、存档备份、导出/导入、错误恢复；重要种子与工具在死亡时保留。
- 菜单暂停并阻断世界操作；键盘、鼠标、触屏移动与交互；全屏和场景/界面缩放。

## 操作与起步

WASD / 方向键移动，Shift 跑步，E 根据附近对象清理、播种、浇水、收获或打开设施。左键使用工具或攻击，1–0 / 滚轮切换快捷栏，R 装填，Tab 背包，C 制作，B 建造，M 地图，J 任务，K 技能，Esc 暂停。建造中 Q 旋转，右键取消。

先看右侧当前重建目标，走到农田清理、播种、浇水并收获两株作物。在N→当前目标确认成果，然后用萝卜加工干粮并领取。M前往住宅区接回阿禾与种子档案，回家完成公共餐桌。后续章节会逐步引导医疗、供水、动力与广播重建；不必同时尝试全部支线。

## 旧版验证与原有系统边界

`npm test` 的53项检查通过：12项原有流程、21项扩展检查和20项本次完善检查，包含从种植、交易、探索、造枪到首次防守的真实动作流程，以及新生产、订单、居民、自动化、钓鱼、养殖、事件和循环守家机制。存档测试覆盖旧版迁移、新版完整恢复、正在进行的尸潮、待领取成品、摊位保留商品和损坏数据拒绝。

场景画布使用实际素材和渲染代码在1366×768、1920×1080、390×844成功绘制，并检查施工阶段、完成建筑、灌溉管线和暴雨夜间探索。营地全部菜单的空状态和有内容状态通过生成检查。当前环境没有此静态项目的受支持真实浏览器预览，因此未完成真实浏览器点击、CSS布局和200%缩放验收；画布检查不等同于浏览器端到端验证。

20项已经接入可游玩流程。探索沿用废墟底图，以侧室选择、路障和补给组合变化；重建有施工和完成外观。居民使用既有角色帧与基础寻路、作息调度；动物与设备使用单帧原创素材。仍未加入季节、独立的各区美术、居民情绪/亲密关系模拟与多人联机。

正式试玩地址保持稳定。同一地址、同一浏览器可以继续原进度；支持手动保存和导出备份。

## 素材

`dist/assets/farm.png`、`ruins.png`、`sprites.png` 是为本项目生成的原创像素风素材。两张底图为 1536×1024，8×8 透明精灵图集为 1254×1254，运行时按自然尺寸切片。未使用参考游戏的角色、UI截图或素材。

v0.2新增 `dist/assets/expansion.png`，原创透明16物件图集。实际尺寸1254×1254，`dist/atlas.js` 使用检查过的来源矩形切片，包含鸡、山羊、鱼、温室、灌溉、太阳能、无人机、防御与生活设施。没有使用参考游戏素材。
