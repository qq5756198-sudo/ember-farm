# 余烬农场 · 持续完善清单

当前版本：**v0.17.0「远方来客」**。基线：v0.16.0「前哨四季」。日期：2026-10-07。

依据的方案：《余烬农场扩展设计方案：20 项玩法 · 20 位人物 · 20 项界面》中标为 v0.17 的 9 项，以及 v0.16.0 记下的三条已知限制。至此方案里的 v0.15–v0.17 三轮都已实施。

## 已完成

- 三项玩法：
  - 夜里的抉择：三片废墟、三种事、每种三个选择，拿走的可以补救，回礼只发一次；
  - 今日险地：浓雾、尸群迁徙、物资漂来，20:00 预告明天；
  - 麦穗的本事：默契 0–15，刨种子、看护鸡舍、提前吠叫、叼回背包。
- 两位人物：
  - 彭姐：借粮 → 雨巷被围 → 解围或送物资 → 互助合同（轮流供粮、守线、尸潮帮手），或没救成后每周买卖；
  - 贺满仓：核账后垫付建设材料，一次一笔，分三期还，不收利息。
- 四项界面：
  - 金色路径与屏幕边缘箭头，办完自动撤下路标；
  - 窄屏的“☰ 菜单”快捷页；
  - 无障碍：大号文字、色弱友好配色、减少闪烁与震屏；
  - 键位自定义（字母键，冲突互换）与手柄。
- 已知限制处理：灰隼团会打居民、队员与围栏；援建队员干活有动作；出货价每天浮动。
- 新增 `far` 存档字段，偏好里多存无障碍与键位；旧档直接读取。
- v0.16.0 及更早已完成项继承；上一轮清单在 development/v0.16.0-ledger.md。

## 已验证

- 514 项自动化测试通过，0 失败（新增 37 项）。
- 实际控制器检查（DOM 替身）新增“远方”段，原七段都通过。
- 无头 Chromium 检查了以下视口，控制台无报错、无横向滚动：
  - 1366×768、1920×1080；
  - 390×844、360×740 触摸模拟；
  - 683×384@2x（相当于 200% 缩放）。
- 独立代码审查加随机操作（6 组 × 2500 步）发现 1 个会坏存档的问题和 9 个其他问题，都已修复并加回归测试；复跑 4 组 × 2000 步，0 失败。
- 详见 releases/v0.17.0.md。

## 待验证

1. 真手柄在各浏览器下的映射与断开重连。
2. 大号文字依赖 CSS `zoom`（旧版 Firefox、Safari 不放大）；色弱配色只覆盖界面，不改场景颜色。
3. 夜里选择、险地奖励、彭姐轮流供粮、垫付分期的数值手感，需要真人试玩；数值在 `dist/farlands-data.js`。
4. 之前各轮留下的手感问题（食堂节奏、节庆上交、相邻加成、寒潮压力、袭击难度）仍待真人试玩。
5. 真机触屏与浏览器自带缩放；Firefox、Safari。手机顶栏用了 CSS `:has()`。

## 待完善 / 下一轮优先级

方案中的 v0.15–v0.17 已全部实施。下一轮建议：

1. 真人试玩一轮，按反馈调数值（自身消耗、袭击、节庆、食堂、险地、垫付）。
2. 已知限制：
   - 提示条和部分场景文字仍写默认键；
   - 灰隼团只打三种防御设施，不在农场时用公式结算；
   - 援建队员动作是叠层，不是新画的动作帧；
   - 色弱配色延伸到场景。
3. 真机与其他浏览器验收后，再考虑 v1.0.0。

开发记录只放在仓库文档中，游戏内没有开发入口；完整验收前不标记 v1.0.0。
