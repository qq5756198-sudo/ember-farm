- 自身消耗与危机感：
  - 玩家饥饿约为最初速度的 2.8 倍，睡觉额外消耗；
  - 饥饿低于 20 时变慢，归零后掉血直至饿晕；
  - 营地每人每天两餐（18:00 晚饭）；缺餐后居民士气下降、队员第二天干活慢一半；
  - 顶栏“口粮 N 天”，小柒在口粮不足时警告；
  - 灰隼团卡路期间物价贵一成。
- 第三至第六段可完整游玩，包裹原主线第二、三章的八个节点，加入以下选择与事件：
  - 先救谁；接回尤可、修复机床并排产；
  - 装车、护送车队；
  - 过路费、备战、补给点、袭击、处置俘虏。
- 灰隼团枪手：瞄准红线、子弹、掩体、撤退；预警、备战加成、不在场自动结算、战败损失与重试、战报。

- 六位人物：唐九、胡二、红薯、蔡眼镜、鹞子、尤可。另有邹叔，接回伤员后留下。
- 六项界面：像素立绘对话、日终总结、产出气泡、消息记录（L）与不遮挡提示、后果预览、防线覆盖图（Z）与战报。
- 修复 v0.12.0 起矮屏 200% 缩放下菜单提示条遮挡菜单内容的问题。
