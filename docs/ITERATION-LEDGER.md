# 余烬农场 · 持续完善清单

当前版本：**v0.21.0「新颜」**。基线：v0.20.0「一亩田」。日期：2026-10-10。

依据的方案：《余烬农场 · 画面大改造方案》。

- 玩家要求一次全部改完：方案原定分三轮（v0.21.0、v0.23.0、v0.24.0），这一版一次做完。
- 七个待定项玩家没有改，都按推荐做：
  - 按农场样张的方向全面铺开；
  - 夜里亮度保持；
  - 像素字只用于标题、数字和按钮；
  - 农场布局不动；
  - 缺水图标画在每块要浇的田上；
  - 新旧画面开关留一个版本；
  - 种菜第二轮顺延到 v0.22.0。

## 已完成

- **十五张地图**：都换成新画的像素底图。
  - 布局、碰撞、出入口、交互点不变；
  - 四个废墟区各画一张；
  - 会变化的地方（路障、货箱、干船坞、检修间、林地、种植位、水渠和生态格子）也是新画法。
- **人物和感染者**：
  - 玩家、居民、援建队员、商人、灰隼团都是新画的像素人物，走路 4 帧，按活计换装；
  - 五种感染者各有画法。
- **建筑、物件和田**：建筑、物件、作物、耕地、田里的状态标记都是新画的；物品图标、动物和鸡窝从原图转成像素。
- **光影和天气**：
  - 一天四段的环境色，窗户、灯、霓虹、火光在夜里发光，修好的边境地点会亮；
  - 雨、雪、雾、高温看得见：水洼会积也会干，暴雨有闪电；
  - 雪原下雪，松林有雾，雨巷总是湿的，地底在室内；
  - 有烟、火星、萤火虫、落叶等粒子。
- **界面**：
  - 木头锈铁的样子，标题、数字、按钮用像素字；
  - 绿色系换成调色板颜色，状态颜色关系和原来一样；
  - 物品图标是像素版，世界地图是旧纸颜色。
- **新旧画面开关**：
  - 在设置和标题页里，存在单独的 `ember-farm-visual-v1`，不碰存档；
  - 原画面和 v0.20.0 一样；
  - 样张预览条已去掉。
- v0.20.0 及更早的已完成项继承下来；上一轮清单在 development/v0.20.0-ledger.md。
